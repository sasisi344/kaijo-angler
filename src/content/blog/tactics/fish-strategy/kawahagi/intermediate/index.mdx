## 太いハリスで挑んで完敗した日

<strong>最初は「エサ取りが上手いなら、こっちも頑丈な仕掛けで対抗しよう」と、太めのハリスと大きめの針で挑んでいました。</strong>結果はエサだけが綺麗になくなる完敗続き。仕掛けを頑丈にするほど、なぜかカワハギとの相性が悪くなるという逆説に気づくまで、何度も同じ過ちを繰り返しました。カワハギ相手には「強さ」ではなく「違和感のなさ」こそが武器になると学んだ瞬間です。

## なぜカワハギは「エサ取り名人」と呼ばれるのか

海上釣り堀でカワハギを狙う際、最も遭遇するトラブルが「アタリがないのにエサがない」という現象です。これはカワハギの捕食スタイルが他の魚とは根本的に異なるためです。

カワハギは<strong>「吸引と吐き出し（バキューム捕食）」</strong>を0.1〜0.3秒で完結させます。おちょぼ口から超高速の水流を作り出し、エサの身だけを吸い出して殻だけを残す、まるで外科手術のような捕食をします。この速度は人間の反応速度（0.2秒）と同等かそれ以下であるため、通常のウキ釣りでは「アタリを見てから合わせる」ことがほぼ不可能です。

中級者がカワハギを攻略するためには、「ウキでアタリを待つ」釣りから、積極的に<strong>「こちらからアタリを作りに行く」</strong>釣りへと転換する必要があります。その核心をなすのが<strong>「ゼロテンション」</strong>の技術です。

## 仕掛けの基本セッティングと選択理由

### カワハギ中級者向け仕掛け構成

| パーツ | 推奨スペック | 理由 |
|------|-----------|------|
| 竿 | 2.4〜3.0m・軟調（グラス素材推奨） | 微細なアタリを感知するために柔軟性が必要 |
| リール | 小型スピニング2000番 | 軽量で感度が損なわれない |
| ライン | フロロカーボン1.5号直結 | 水中での見えにくさ・感度バランス |
| 針 | カワハギ専用3号（3本針仕掛け） | 多点狙いで効率アップ |
| エサ | アサリ（むき身・ベロ部分） | 吸い込みに最適な柔らかさ |
| オモリ | 8〜12号（底に着く重さ） | 底でのタタキに必要な安定性 |

### エサの持参量の目安

カワハギは1匹がエサを取ると即座に次のカワハギが来るため、エサの消耗が激しいです。半日釣行（5時間）でアサリむき身を<strong>50〜80個分</strong>（2〜3パック）は準備しましょう。

## ゼロテンションとは：違和感の極限排除

### なぜ「張り」がカワハギを逃がすのか

カワハギがエサを吸い込む際、ラインの張りをわずかでも感じると、その場で吐き出してしまいます。これは「エサを飲み込む際に何か引っ張られる感覚＝危険」という学習によるものです。

ゼロテンションとは、仕掛けのオモリを底に着け、ラインの張りを「張らず、緩めず」の絶妙な状態に保つことを指します。

| ライン状態 | カワハギの行動 | 釣果への影響 |
|---------|-------------|----------|
| ピンと張った状態 | 吸い込みを即座に感知して吐き出す | 全くアタリが出ない |
| わずかにたるんだ状態 | 吸い込んだ際の抵抗が小さい | アタリが出やすい |
| ゼロテンション（理想） | 抵抗なしで奥まで吸い込む | フッキング率が高い |
| 緩ませすぎ | アタリが全く感知できない | 合わせのタイミングが分からない |

### ゼロテンションの作り方

1. 仕掛けを目的のタナ（底から数cm）に合わせる
2. 竿先を<strong>5〜10cm前方（水面方向）</strong>に送り出す
3. 水面に出ているラインが<strong>わずかなたるみ（S字の弛み）</strong>を描いていれば理想
4. アタリは「クンッ」という穂先の小さな動きか、ラインが「スッ」と走ることで感知する

## 宙釣りとハワセの臨機応変な切り替え

カワハギの活性によって、タナを数センチ単位で入れ替えます。

### 宙釣り（中層に浮かせる）

- <strong>使う場面</strong>：活性が高い時・放流直後
- <strong>タナ</strong>：底から<strong>20〜50cm</strong>上
- <strong>理由</strong>：エサが中層に浮いていることでカワハギに「発見させやすく」し、競争心が働いてアタリがより明確に出やすい

### ハワセ（底に寝かせる）

- <strong>使う場面</strong>：活性が低い時・スレ時間帯
- <strong>タナ</strong>：底網の上に仕掛けが<strong>寝ている</strong>状態（オモリが底に着いたまま）
- <strong>理由</strong>：目の前にエサが転がっている状態はカワハギにとって「労せず食べられる」最善の演出になる

### 状況別の切り替えサイン

| 状況 | 最適なタナ | 主な誘い方 |
|------|---------|---------|
| 放流直後 | 底から30〜50cm（宙） | シェイク＋静止 |
| 1時間後（普通） | 底から10〜20cm（ハワセ気味） | タタキ→静止→聞き |
| 食い渋り | 底べた（ハワセ） | 静置のみ→ゆっくり聞き |
| 完全スレ | 底から5〜10cm（超ハワセ） | ゼロテンション＋微振動 |

## 「聞き」と「タタキ」のコンビネーション

### タタキ（誘い）の方法

ただ置いておくのではなく、アクションを加えてカワハギの好奇心を煽ります。

1. <strong>タタキ</strong>：竿先を小刻みに上下シェイク（1秒に3〜5回・振り幅3〜5cm）して仕掛け全体を暴れさせる。砂煙が舞うような感覚
2. <strong>静止（ゼロテンション）</strong>：パタッと動きを止め、カワハギがエサに食らいつく「間（ま）」を<strong>3〜5秒</strong>作る
3. <strong>聞き合わせ</strong>：竿先を<strong>5〜10cmだけゆっくり</strong>持ち上げる。重みや抵抗があれば本アワセを入れる

### 合わせのタイミング

カワハギのアタリは2種類あります：
- <strong>能動的アタリ</strong>：穂先が「コクン」と下に押さえ込まれる → 即座に合わせ
- <strong>受動的アタリ</strong>：聞き合わせで重みが感じられる → そのまま竿を立てる（スイープアワセ）

## 季節別のカワハギ攻略：水温と活性の変化に対応する

### 水温とカワハギの行動変化

| 水温 | 季節 | 行動パターン | 最適なタナ設定 |
|-----|-----|-----------|------------|
| 10〜14℃ | 冬 | 底に張り付いて動かない | 完全ハワセ（底べた） |
| 15〜19℃ | 春・秋 | アクティブに動き始める | ハワセ気味（底から5〜15cm） |
| 20〜24℃ | 初夏・初秋 | 最も活発・中層まで浮く | 宙釣り〜ハワセを組み合わせ |
| 25℃以上 | 夏 | 朝のみ活発・昼は鈍い | 早朝のみ宙釣りで集中攻略 |

### 放流直後の「スーパー活性タイム」

施設での放流直後（1時間以内）は、カワハギが環境に慣れておらず競争心が高まっています。

<strong>放流直後の攻略法</strong>：
1. 放流されたと確認したら即タナを30〜50cmに上げる（宙釣りモード）
2. タタキを積極的に行い砂煙を立てる（食欲を刺激）
3. アタリが連続する「時合い」に集中して数を稼ぐ
4. 食いが落ち始めたら（1〜2時間後）ハワセモードに移行

## カワハギ釣りの「立ち位置」戦略：どの場所が有利か

### イケス内でのカワハギの分布特性

カワハギは底に生息し、砂・礫底の甲殻類・貝類を好む魚です。海上釣り堀では、以下の場所に集中しやすい傾向があります。

| 場所 | カワハギが集まりやすい理由 | 釣り座の優先度 |
|-----|---------------------|----------|
| 底網の継ぎ目・縁 | 底の凸凹に甲殻類が溜まりやすい | 高い |
| イケスの隅（コーナー） | 底が隅に向かって傾斜している施設が多い | 高い |
| 桟橋下・陰になる部分 | カワハギは直射日光を避ける傾向 | 高い |
| イケス中央 | 開けた場所は警戒心が増す | 低い |

釣り座選びの段階で<strong>「コーナーや桟橋下の釣り座」</strong>を選ぶだけで、カワハギとの遭遇頻度が大幅に上がります。施設に到着したら、まず底の見える場所を偏光グラスで観察してカワハギの影を探しましょう。

### 潮の流れとタナの関係

潮が動く時間帯は、カワハギが底から少し浮き上がる傾向があります。

- <strong>潮が流れている時</strong>：タナを底から10〜20cm上げて宙釣り気味にする
- <strong>潮が止まっている時</strong>：完全ハワセで底べたを攻める
- <strong>朝一の潮の変わり目</strong>：最も食いが立つ「時合い」となることが多い

## よくある失敗と対策（FAQ）

<strong>Q：ゼロテンションにしたらアタリが全く分からなくなった</strong>
→ たるませすぎている。ラインはS字を描く程度のわずかな弛みが理想。穂先で感知できなくなった場合は「聞き合わせ」を頻繁に行い、重みで存在を確認する。

<strong>Q：タタキをしてもアタリが出ない</strong>
→ カワハギが底に張り付いている「完全ハワセ」モードに入っている可能性。タタキをやめて仕掛けを底に寝かせ、3〜5分完全静置してから一度だけゆっくり聞き合わせをする。

<strong>Q：アタリは感じるがすぐにエサがなくなる（合わせが決まらない）</strong>
→ エサが柔らかすぎる（カワハギに吸い出されている）か、合わせが遅すぎる。エサは前日に塩水に漬けて締めたアサリ（身が固くなる）を使い、アタリを感じた0.5秒以内に合わせる。

<strong>Q：エサを何度付け替えてもなくなる（カワハギ以外が取っている）</strong>
→ カワハギ以外の外道（マダイ・フグ）がエサを取っている可能性。殻付きのアサリか、カニのエサに切り替えることで外道を物理的にフィルタリングできる。

<strong>Q：カワハギが一瞬で取り込んでネットまで届かない（バラシが多い）</strong>
→ カワハギは急に引きが強まることはなく一定の抵抗なので、バラシの多くは針が皮1枚に掛かっている「皮一枚」の状態。聞き合わせで重みを確認した後は「素早く一定速度」で巻き上げる。止まったり緩めたりすると針穴が広がってバラシになる。

<strong>Q：冬に行ったが全くアタリが出なかった</strong>
→ 冬のカワハギは底ベタに張り付いて完全静止している。完全ハワセ（オモリが底に着いた状態）にして、5〜10分完全静置→ゆっくり1cm聞き上げるサイクルを繰り返す。またエサの鮮度が特に重要になるため、古いむき身ではなく当日鮮度の高いものを使う。

## まとめ：ターゲットの警戒心をハックせよ

カワハギ中級攻略のポイントは3つです。

1. <strong>ゼロテンションでラインの張りをS字の弛みまで緩め、カワハギが感じる抵抗をゼロにする</strong>
2. <strong>3〜5秒のタタキ後に完全静止し、「食わせの間」を作ってアタリを集中させる</strong>
3. <strong>活性が高い時は宙釣り・低い時はハワセに切り替え、常にカワハギがエサに触れやすいタナを提供する</strong>

ゼロテンションで違和感を消し、タタキで興味を引き、聞き合わせで確実に仕留める。この三位一体の攻略ができれば、あなたも立派な「カワハギマスター」の仲間入りです。
