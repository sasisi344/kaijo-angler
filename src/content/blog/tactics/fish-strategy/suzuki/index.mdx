海上釣り堀のスズキは、マダイより上の中層〜表層にいて、動くエサに強く反応する魚です。活きアジがなければサバやサンマの皮付きの切り身を動かして止める誘いで食わせ、掛けたら竿を寝かせ気味にして、水面で頭を振るエラ洗いで針を外されないようにします。

切り身を横へ動かし、止めたところで糸が引かれる。重さが乗ったら、今度は水面へ浮こうとする魚をタモまで導きます。誘いと取り込みの両方に出番があるのが、スズキのエサ釣りです。

## スズキとは（シーバスは別名）

スズキはシーバスとも呼ばれ、海上釣り堀でも放流する施設が増えている魚です。特徴は動くエサへの反応と、掛けた後に水面で首を振る「エラ洗い」にあります。

難易度の目安は中級。エサを食わせるだけでなく、跳ねる魚に竿を追従させ、針やハリスに急な力を掛けないやり取りも楽しみの一つです。

活きエサを泳がせる釣りと、自分で切り身を動かす釣りを、その日のエサの用意に合わせて選べます。

## 基本情報まとめ

スズキは中層〜表層の2〜4m付近を基準に、壁際や支柱の周辺を探ります。ハリス3〜4号・伊勢尼10〜12号は目安とし、施設のおすすめに合わせます。

| 項目 | 内容・目安 |
|---|---|
| タナ（エサを置く深さ） | 中層〜表層、2〜4m付近。マダイより上を意識 |
| 狙う位置 | 支柱の根元・壁際・コーナー |
| 反応を狙う時間 | 朝マズメ・放流直後 |
| シーズン | 春〜初夏と秋。適水温は20〜25℃が目安 |
| 活きエサ | 活きアジ、活きイワシ |
| 死にエサ | サバ・サンマの皮付き切り身、キビナゴ、ササミ |
| ハリス | フロロカーボン3〜4号が目安 |
| 針 | 伊勢尼10〜12号が目安 |
| ドラグ | やや緩め。急な首振りを受け流す |

## スズキの習性（吸い込みと、動くものへの反応）

スズキはエサを水と一緒に口へ吸い込み、横に動くものや、動きが止まった瞬間に反応します。吸い込みを妨げないよう、誘いの後は糸を引っ張り続けず、食い込む余地を残します。

### 中層から、壁際・支柱を探る

マダイを狙う底のタナのまま待つより、まずは上の層へエサを届けます。壁際や支柱は狙いどころですが、針を網へ寄せすぎない位置から始めます。

反応がなければ、投入する角度やタナを変えます。同じ深さだけを引き続けるより、魚のいる層を探し直すことが先です。

深さの測り方は、[海上釣り堀のタナの基本](/column/trivia/tana-basics/)で紹介しています。

### 小さなアタリの後に、追い食いすることも

小さなアタリが続いてから、大きな引き込みへ変わる場合があります。最初の動きでエサを引き抜かず、重みが乗るまで待つと、追い食いに対応できます。

吸い込ませようとしてハリスを極端に細くする前に、糸の張りやオモリの抵抗を見直します。掛けた後の擦れにも備えるため、号数は施設に合うものを使います。

## エサ: 活きエサと切り身

活きエサは活きアジ・活きイワシ、切り身はサバ・サンマの皮付きが基本です。キビナゴも死にエサの選択肢になり、切り身と同じく動かして使います。

### 活きアジは、自然に泳がせる

活きアジは背掛けにし、投入したら自然に泳がせます。活きイワシも使えますが、動きを足し続けるより、エサ自身の泳ぎを生かします。

ウキや糸の動きを見て、エサが泳いでいるかを判断します。泳ぎが鈍ったら、元気なものに替えます。

### 切り身は皮を残して付ける

サバ・サンマの切り身は、銀色の皮が水中で見える向きに付けます。皮の端から針を通し、先がひらひら動く余地を残すと、横移動や落下の動きを付けやすくなります。

身が崩れやすいときは、薄く塩をまぶす塩締めや、硬い皮の部分で固定する方法があります。大きな塊を付けるより、魚が口へ取り込みやすく、動かしやすい形に整えます。

| エサ | 使い方の要点 |
|---|---|
| サバの皮付き切り身 | 皮を見せ、横へ動かして止める |
| サンマの皮付き切り身 | 崩れやすければ塩締めし、皮で保持する |
| キビナゴ | 横移動と落下を組み合わせる |
| ササミ | 切り身への反応が遠いときの変化として、動かして使う |

## 死にエサを動かす誘い方

死にエサは、狙うタナでゆっくり横に動かして止め、そこから落とすのが基本です。スズキは止めた瞬間や落下中に食うことが多いため、動かし続けず、食わせる間を作ります。

### 横へ動かして、止める

1. 中層〜表層の狙うタナへエサを入れる
2. 竿やリールでゆっくり横へ動かす
3. 動きを止め、エサを漂わせる
4. 糸の動きと重みを見ながら、次の誘いへ移る

動かす幅は周囲の仕掛けと網までの距離に合わせます。横へ引ける範囲が狭いなら、無理に広く引かず、上下の動きで見せ直します。

### 持ち上げて、落とす

竿先でエサを少し持ち上げ、竿を戻して落下させます。糸を大きくたるませるとアタリが見えにくいので、落ちていく糸の変化を追える状態にします。

落下中にアタリが出ても、すぐ次の誘いで引き抜かず、重みが乗るかを見ます。針が底網に触れる深さまで落とさず、狙っているタナの中で動かします。

### 食わないときは、動きを小さくする

大きな動きを続けるより、ほぼ止まっているような小さな動きに反応することもあります。誘いが空振りなら、速さを上げる前に、止める間とタナを変えます。

竿先でエサを動かす道具や操作を詳しく知りたいときは、[ミャク釣りのタックルと死にエサの誘い方](/tactics/gear/myakuzuri-gear/)へ進んでください。

## エラ洗い対策と取り込み

エラ洗い対策は、竿を寝かせ気味にして魚を水面へ出さず、ドラグをやや緩めにすることです。跳ねたら竿を追従させて糸を張りすぎず、着水後に張りを戻しますが、魚のサイズによっては完全には防げません。

### 浮き上がる動きに、竿を合わせる

スズキが急に浮く、頭を振る、水面に泡が出るといった動きが、跳ねる前の目印になります。竿先を水面側へ下げ、上へ引き上げ続ける状態を避けます。

網際へ走るときは、イケスの中央側へ竿を向けます。竿を倒す方向が壁側にならないようにし、魚の向きを変えながら距離を詰めます。

| 局面 | 対応 |
|---|---|
| 水中で走る | 竿を寝かせ気味にし、曲がりとドラグで受ける |
| 急に浮く・頭を振る | 竿先を水面側へ下げる |
| 跳ねた | 竿を魚に追従させ、糸に急な力を掛けない |
| 着水した | 余分な糸を巻き、張りを戻す |
| タモの手前 | 頭をタモへ向け、水中からすくう |

### ハリスは、擦れたら結び直す

取り込んだスズキを収め、次のエサを付けようとすると、指先にハリスのざらつきが触れます。その傷を残すと、次に掛けた魚を取り込みまで運べなくなります。

水面で頭を振る際にエラぶたなどへ糸が触れると、ハリスは擦れて傷みます。太さだけを頼りにせず、やり取りの後に傷んだ部分を替えることが大切です。

用意する基準は、<strong>施設のおすすめに合う号数（目安は3〜4号）の、結び直し用フロロハリス</strong>。交換分を手元に置けば、傷を見つけたところで次の一投の準備に移れます。

グランドマックスFXは、その交換用に選ぶハリスの一つです。自分で針を結ぶ人なら、必要な号数を選んで予備を用意できます。

針を自分で結ばない人は、施設のおすすめに合う完成仕掛けを予備にしておくと、仕掛けごと交換できます。

### タモは、魚を浮かせる前に用意する

掛けたら周囲へ「スズキが掛かりました」と知らせ、タモを用意します。魚を追い回してすくうより、頭をタモの方向へ向けて、水中から受ける流れです。

取り込んだ後も暴れるので、濡れたタオルで固定し、エラぶたや背びれのトゲへ素手を近づけないようにします。

## 季節と時間帯

春〜初夏と秋はスズキを狙いやすい季節で、時間帯は朝と放流直後が目安です。夏は朝の涼しい時間を中心に、冬は底付近で静かに待つ釣りへ切り替えます。

| 季節・状況 | 狙い方 |
|---|---|
| 春〜初夏 | 中層〜表層で活きエサへの反応を見る |
| 秋 | 切り身の動きにも反応を探り、取り込みへ備える |
| 夏 | 朝を中心に。高水温なら深めのタナも探る |
| 冬 | 底付近で置き釣り。誘いを小さくする |
| 風で水面が波立つ日 | 浅めのタナも試す |

放流のタイミングを釣りに組み込む準備は、[海上釣り堀の放流タイム](/column/trivia/stocking-time-strategy/)にまとめています。放流直後でも、当日の反応でタナと誘いを調整します。

## 持ち帰り

スズキは鮮度が落ちやすいので、釣ったら締め・血抜きをして早く冷やします。調理前は腹の黒い膜と血合いを歯ブラシで洗い落とすことが、臭みを抑える大切な工程です。

### 黒い膜と血合いを残さない

1. 腹を開き、内臓を取り出す
2. 腹の黒い膜と背骨まわりの血合いを見る
3. 調理用の歯ブラシと流水で洗い落とす
4. 洗った後の水気を拭き取る

身を強くこすらず、膜と血合いを丁寧に落とします。冷やす段取りと下処理をセットで考えると、釣った魚を食卓へ運びやすくなります。

### 釣った日は洗い、翌日は焼き物に

釣った日の食べ方には、薄く切った身を氷水にさっと通して水気を取る「洗い」があります。翌日は塩焼きやムニエルに分けると、同じ白身でも違う食感を楽しめます。

日数だけで生食の可否を決めず、処理と保冷の状態に合わせて食べ方を選びます。

## よくある質問

### 活きアジがなくても釣れますか？

サバ・サンマの皮付き切り身やキビナゴが使えます。止めたまま待つだけでなく、横に動かして止める誘いを試します。

### 切り身を動かしてもアタリがありません

まずタナを見直します。中層〜表層を基準に、動きを小さくしたり、通す角度を変えたりして反応を探ります。

### アタリはあるのに空振りします

追い食いの途中で合わせている可能性があります。最初の小さなアタリで引き抜かず、引き込みや重みが乗るところを待ちます。

### エラ洗いは竿を下げれば防げますか？

竿を寝かせることは対策になりますが、魚のサイズや動きによって跳ねる場合があります。跳ねたときの追従と、着水後に張りを戻す操作まで準備します。

### ハリスの号数はどれくらいですか？

3〜4号を目安に、施設のおすすめへ合わせます。一度やり取りした糸は傷を見て、ざらつきがあれば結び直すか交換します。

### 持ち帰ったスズキの臭みを抑えるには？

早く冷やし、内臓を取り、腹の黒い膜と血合いを洗い落とします。味付けの前に、この下処理を丁寧に進めます。

## まとめ

行き先が決まったら、次の3つを準備しておきます。

1. 上の施設表から利用する場所を選び、スズキを狙うエリアとエサを決める
2. 切り身を使うなら、[ミャク釣りの誘い方](/tactics/gear/myakuzuri-gear/)を読み、動かして止める操作を覚える
3. ハリスの予備・タモ・持ち帰りの保冷をそろえる

切り身を止めた瞬間の引き込みから、水面の首振りをいなしてタモへ。その日の洗いと翌日の塩焼きまで、スズキ一匹で楽しみが広がります。
