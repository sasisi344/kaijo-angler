釣ったマダイは、当日はコリコリした食感、数日寝かせると身がやわらかくなりうま味が増します。うま味の強さは<strong>熟成14日目が最も高い</strong>というデータがあり、血がしっかり抜けていれば10日以上寝かせることもできます。

締めと血抜きは、海上釣り堀なら施設が無料か有料でやってくれることが多く、<strong>自分でやらなくてもかまいません</strong>。この記事では、施設に任せる選び方、自分で締めて持ち帰るときの手順、家のチルド室で寝かせる方法、寝かせたあとの食べ方を順に説明します。

## マダイは何日寝かせるとおいしいか

結論は、うま味を最大にしたいなら14日目、やわらかさと食感のバランスで食べるなら数日目からです。マダイのうま味の強さは熟成14日目が最も高く、遊離グルタミン酸は14日間で約3倍になるというデータがあります。

### 当日は食感、寝かせるとうま味

釣りたてのマダイは、コリコリした歯ごたえが一番強い状態です。一方、うま味は寝かせるあいだに増えていきます。

魚の筋肉にはATP（アデノシン三リン酸）という物質があり、死後は次のように分解されます。

```
ATP → ADP → AMP → IMP（イノシン酸）→ イノシン → ヒポキサンチン
                       ↑
              うま味のもとになる成分
```

IMP（イノシン酸）は、昆布や出汁のうま味であるグルタミン酸と合わさると、うま味が強く感じられる成分です。熟成では、タンパク質も自己消化酵素で分解されて、イノシン酸やグルタミン酸が増えていきます。

### 日数ごとの変化

| 釣ってからの日数 | 身の状態 | うま味 | 食感 |
|----------------|---------|------|------|
| 当日（〜数時間） | 死後硬直の前〜硬直中 | まだ薄い（ATPが多い） | コリコリ（最も強い） |
| 1日後 | 死後硬直がとけ始める | 出始める | やわらかくなり始める |
| 2〜3日後 | やわらかさとうま味のバランスがよくなり始める | 増えていく | ねっとり、甘みが出る |
| 6日目ごろ〜 | 血が残っていると、臭みが出始める | — | — |
| 14日目 | 血がしっかり抜けた身 | <strong>強さが最も高い</strong> | やわらかい |

血が残っていると、血が脂を酸化させて、マダイでは6日目ごろから臭みが出ます。逆に血を完全に抜けば、10日以上の長い熟成もできます。熟成の日数を決めるのは、日数より先に血抜きの出来です。

## 締めと血抜きは施設に頼める

海上釣り堀では、締め・血抜き・下処理を施設がサービスでやってくれることが多く、自信がなければ有料で頼める施設もあります。当サイトの施設記事116本のうち36本が、締めや下処理・調理などのサービスを「あり」としています（2026年11月17日時点）。

- <strong>[横浜釣り堀王国](/fishing-facility/yokohama-tsuribori-okoku/)</strong>（屋内の釣り堀。マダイも対象魚）: 活け締め・下処理まで無料。調理は別料金
- <strong>[海上釣り堀まるや](/fishing-facility/kaijo-tsuribori-maruya/)</strong>（静岡県沼津市）: 下処理は有料。スタッフが巡回して、タモ入れや釣った直後の血抜きも手伝ってくれます
- <strong>[海上釣り堀 太公望](/fishing-facility/kaijo-tsuribori-taikoubou/)</strong>（静岡県熱海市）: 併設の市場食堂で、釣ったマダイを調理してもらえます

施設によって、無料か有料か、どこまでやってくれるかは違います。予約のときか受付で、締めと血抜き、内臓出しまで頼めるかを聞いておくと、その日の持ち帰りが決まります。

## 釣り場での処理（自分でやるなら）

自分で処理して持ち帰るなら、熟成の成否は釣り場での最初の5分で決まります。血が残ると酸化が進んで、臭みと変色の原因になります。魚が暴れながら死ぬと、うま味のもとのATPが急に使われて、寝かせても増えるうま味が減ります。

### 手順1：脳締め（30秒以内）

- アイスピックや締め具で、<strong>目の後方の硬い部分（頭蓋骨）</strong>に一突きする
- 脳を壊して一瞬で締めると、魚が暴れず、ATPを温存できる
- 指で目を覆うように持ち、刺す角度を決めてから行う

### 手順2：血抜き（5分）

- エラぶたを開け、<strong>エラの付け根（エラ弓）をナイフで切る</strong>
- 切るのは片側だけでもよいが、両側を切ると血が出やすい
- 海水を入れたバケツに頭を下にして入れ、5〜10分血を出す
- 水が赤くなったら交換する

ホースの水圧で全身の毛細血管まで血を押し出す方法もあり、津本式と呼ばれます。専用の道具が要るため、まずは脳締めとエラ切りだけでも十分に始められます。

### 手順3：神経締め（任意）

- 尾の側線付近を切ると、尾の動脈から血がさらに抜ける
- 鼻の穴から細いワイヤーを通して脊髄の神経を壊すと、死後硬直を遅らせられる
- 脳締めと併せると効果的で、熟成に入るまでの時間を調整できる

### 手順4：冷やして持ち帰る

血を抜いて締めたマダイを海水のバケツから上げたら、クーラーに入れて帰ります。ここで魚の温度が上がると、寝かせる前に身が傷んでしまいます。

家で熟成させるときは、魚体の中心温度を0〜2℃に保つのが目安です。この冷たさを、帰り道から崩さないことが前提になります。

選ぶ条件は、<strong>マダイが丸ごと入る長さと、真空パネルのように断熱性が高い構造</strong>です。シマノのスペーザ リミテッド 35L は、60cm級の魚まで入る3面真空パネル構造で、キャスターも付いています。その条件で選ぶ製品の一つです。

## 家での熟成のやり方

家では、冷蔵庫のチルド室（0〜1℃）に入れて寝かせます。食品が凍る寸前の温度で、熟成に向いた環境です。

### 内臓とエラを先に抜く

釣り場で血を抜いたマダイは、家に着いたら次の順で処理します。

1. <strong>エラを取る</strong>：エラ穴からハサミで切る。エラには細菌が多く、腐敗の起点になる
2. <strong>内臓を取る</strong>：腹を開いて内臓を出す。破かないようにゆっくり
3. <strong>腹の中を洗う</strong>：水（できれば塩水）で、血合いと残りかすを洗い流す
4. <strong>水気を拭く</strong>：キッチンペーパーで、表面と腹の中の水気をすべて拭く。水分が残ると腐りやすい

### チルド室での保管

```
① キッチンペーパーで全体（腹の中も）を包む
② ラップで密封する（または真空パック）
③ チルド室（0〜1℃）に入れる
④ 毎日ペーパーを替える（湿ったらすぐ替える）
```

氷水を使う方法もあります。魚をポリ袋に入れて、氷水を張った容器に浮かべると、自分の重みで身がつぶれず、温度も安定します。

毎日、袋の破れや温度の変化を見て、魚から出るドリップをきれいなペーパーで拭き取ります。保存シートを使っているなら、必要に応じて替えます。

### パーシャル室は切り分けるときに

パーシャル室（−1〜−3℃）は、表面がわずかに凍って酸化を抑えられます。熟成が進んでやわらかくなった身を、きれいにサクに切るときに向いています。熟成そのものの進みは、チルド室のほうが向いています。

### 真空パックで空気を遮断する

家のチルド室で何日も寝かせるあいだ、袋の中に空気が残っていれば、その間も酸化が進みます。空気を遮断して弱い真空の状態にすると、酸化と雑菌の増え方を抑えられます。

寝かせる日数が長くなるなら、<strong>袋の空気をしっかり抜けること</strong>が条件です。東洋プランの真空パック機は、釣った魚の鮮度を家で保ちたい人向けの製品で、その条件に合う一つです。

## 大型と、施設に頼まないときのおろし方

2kg以上の大型は、三枚におろしてから熟成させると、身の全体に均一に熟成が進みます。骨がついたままだと、骨のまわりから腐りやすくなることがあります。各フィレをペーパーで包んでラップをかけ、チルド室に入れるのが安全です。

施設で下処理を頼まず、丸のままのマダイを持ち帰った日は、台所でエラと内臓を抜く作業から始まります。エラの付け根や中骨のまわりには硬いところがあり、血合いも残ります。

選ぶ基準は、<strong>サビにくく、洗って手入れがしやすい出刃</strong>です。貝印の関孫六 銀寿は、刃渡り約165mmのステンレス出刃で、柄は天然木です。家で3枚におろす人に向いています。

## 熟成マダイの食べ方

寝かせたマダイは、日数と食べ方を組み合わせると味が決まります。

### 刺身（数日目〜）

数日寝かせた身は、ねっとりした甘みが出ます。

- 熟成で身がやわらかくなるので、薄く削ぎ切りにする
- <strong>岩塩とオリーブオイル、スダチ</strong>：マダイ本来の甘みが前に出る
- <strong>わさび醤油</strong>：定番で、熟成の甘みとの対比がはっきりする

### 炙りと塩焼き

- <strong>炙り（松皮造り）</strong>：皮目をバーナーか直火でさっと炙る。皮の下の脂が溶け出して香ばしく、すぐ氷水で締めると皮はパリッと、身はしっとり仕上がる
- <strong>塩焼き</strong>：2日目くらいの熟成でも十分においしい。焼く前日から塩を当てて水分を出し、強火で皮目をパリッと焼く。うま味が凝縮されていて、塩だけで味が決まる

### 鯛めしと潮汁

身だけでなく、アラ（頭と骨）も最高の出汁になります。

1. アラを霜降り（熱湯のあとに氷水）にして、血合いを落とす
2. 昆布・酒・塩で薄めに味をつけた出汁で、ご飯と一緒に炊く
3. 炊き上がったらアラから身を外して混ぜる
4. 木の芽・三つ葉・ゴマを散らす

マダイのイノシン酸と昆布のグルタミン酸が合わさって、鯛めしは一口でおかずがいらなくなる味になります。アラは潮汁にしても出汁がよく出ます。

## よくある質問

<strong>Q：マダイは何日熟成させればよいですか</strong>
→ うま味の強さが最も高いのは14日目です。やわらかさとうま味のバランスは、2〜3日目からよくなり始めます。食感の好みで数日目に食べてもかまいません。血がしっかり抜けていれば、10日以上寝かせることもできます。

<strong>Q：熟成に血抜きは必要ですか</strong>
→ 必要です。血は脂を酸化させて臭みのもとになります。血を完全に抜けば長く寝かせられますが、血が残るとマダイでは6日目ごろから臭みが出ます。

<strong>Q：海上釣り堀で締めや血抜きをしてもらえますか</strong>
→ 締めや下処理をしてくれる施設は多く、無料の施設と有料の施設があります。予約のときか受付で聞いておくと、その日の持ち帰りが決まります。

<strong>Q：熟成させたら臭みが出ました</strong>
→ 血抜きが足りなかった可能性が高いです。血が残ったまま寝かせると酸化して臭みになります。保管温度が高すぎても臭みが出るので、冷蔵庫の棚ではなくチルド室に入れます。

<strong>Q：神経締めの道具を持っていません</strong>
→ 神経締めは必須ではありません。脳締めと血抜きだけでも、十分によい熟成ができます。神経締めは、死後硬直を遅らせて熟成に入る時間を調整したいときの追加の手段です。

<strong>Q：釣り場で血抜きをする時間がありません</strong>
→ 少なくとも「脳締め、エラ切り、海水バケツへ入れる」までの30秒は行います。帰宅後に腹を開いて内臓を出し、洗えば、釣り場での血抜きに近い効果が得られます。

<strong>Q：熟成したマダイと、新鮮なマダイの見た目の違いは</strong>
→ 熟成が進むと、身の色がわずかに黄みを帯びて透明感が増します（乳白色からアイボリー色へ）。臭みがなく、ほのかに芳醇な香りがすれば、熟成はうまくいっています。暗い赤色への変色や酸っぱい香りは、過熟成か処理不良のサインです。

<strong>Q：マダイ以外の魚でも、同じ日数でよいですか</strong>
→ 魚種で、うま味の強さが最も高くなる日が違います。ブリは7日目、シマアジは4〜5日目が目安です。マダイの14日目とは別に考えます。

<strong>Q：真空パック機がないときの代わりの方法は</strong>
→ ラップを二重にして、空気が入らないように密着させます。ジップロックなどの袋に水を入れて空気を押し出す「水押し密封」も使えます。完全な真空にはなりませんが、空気との接触を減らせます。

## まとめ：下処理のある施設を選んで、寝かせる日を決める

締めて血を抜いたマダイを、チルド室で数日から2週間ほど寝かせると、当日の刺身とは違うやわらかさとうま味が出ます。数日後の夜、薄く引いた刺身を岩塩とオリーブオイルで口に運ぶところまでが、この釣りの楽しみです。

<strong>出かける前に決めておくこと</strong>

- 締め・血抜き・下処理を、施設に頼むか自分でやるか
- 頼むなら、無料か有料か。調理は別料金か
- 持ち帰るマダイが丸ごと入るクーラーの大きさ

下処理のある施設は、[海上釣り堀まるや](/fishing-facility/kaijo-tsuribori-maruya/)や[海上釣り堀 太公望](/fishing-facility/kaijo-tsuribori-taikoubou/)などの施設記事から探せます。釣り方は[マダイの釣り方](/tactics/fish-strategy/madai/)、遠征先から家へ送る方法は[釣った魚の配送ガイド](/column/travel/fish-shipping-guide/)にまとめています。
