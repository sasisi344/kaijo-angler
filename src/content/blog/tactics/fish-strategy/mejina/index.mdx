メジナ（グレ）は、海上釣り堀で放流している施設が限られる、引きの強い魚です。細めのハリスに小さめのむきエビやオキアミを付けて中層〜底を探り、持ち帰ったら血抜きと背骨まわりの血合い（背わた）を洗い流すと、臭みを抑えて食べられます。

小さなウキの動きを追っていると、竿先が一気に網際へ引かれる。繊細なエサの見せ方と、掛けた後の力強い引きの両方を楽しめる魚です。

## メジナ（グレ）とは

メジナはグレとも呼ばれる、引きの強い魚です。海上釣り堀で放流している施設は限られるので、まずは行き先の対象魚に入っているかを見て選びます。

難易度の目安は中級。警戒心が強く、仕掛けを自然に漂わせることと、掛けた後に網際へ突っ込ませないことが要点です。

同じエサへの反応が変わる場合もあり、小さなむきエビを基本に、タナやエサを替えて探ります。

## 基本情報まとめ

メジナは中層〜底を、小さめのエサと軽い仕掛けで狙います。ハリス1.5〜2号・グレ針4〜6号を目安に、施設のおすすめへ合わせます。

| 項目 | 内容・目安 |
|---|---|
| タナ（エサを置く深さ） | 中層〜底付近。まず水深の半分から |
| 深さの目安 | 3〜6m付近。イケスの水深に合わせる |
| 狙う時間 | 朝マズメ・水温が安定している時間・放流直後 |
| シーズン | 秋〜春。水温15〜20℃が目安 |
| 定番エサ | 小さめのむきエビ、オキアミ |
| 替えのエサ | ボイルオキアミ、練りエサ、シラサエビ、麩、パン、コーン |
| ハリス・針 | フロロハリス1.5〜2号、グレ針4〜6号 |
| オモリ | できるだけ軽く。G5〜G3程度のガン玉が目安 |
| ドラグ | やや緩めにし、突っ込みをいなす |

## 釣り方の要点

メジナは水深の半分からタナを探り、小さなエサ・軽いオモリ・細めのハリスで自然に漂わせます。掛かったら竿の弾力とやや緩めのドラグで引きを受け、網際への突っ込みを中央側へいなします。

### 水深の半分から、上下へ探る

最初は中層へ入れ、反応がなければ少しずつ深くします。朝や曇り・濁りのあるときは、浅めのタナも試します。

1. 水深の半分を基準に始める
2. アタリがなければ、底網へ掛けない範囲で深くする
3. 深い場所で反応がなければ浅めへ戻す

周囲でメジナが釣れた深さも手がかりです。深さの測り方は、[海上釣り堀のタナの基本](/column/trivia/tana-basics/)にまとめています。

### エサを小さく、仕掛けを軽くする

むきエビやオキアミを小さめに付け、オモリで強く引っ張らずに沈めます。このようにエサやハリスが自然に水中へ入ることを「なじませる」といいます。

G5〜G3程度のガン玉を目安に、エサの沈み方と流れを見て調整します。軽くすることだけを目的にせず、狙うタナまで届く組み合わせを選びます。

ハリス1.5〜2号・グレ針4〜6号は基準です。施設のおすすめに合わせ、同じイケスにいる魚のサイズも考えて組みます。

撒き餌（コマセ）を使うかどうかは、施設の規則に従います。エビを針に付けることと、周囲へ撒くことを同じ扱いにはしません。

### 消し込みに合わせ、網際から離す

ウキがピクピク動く段階では、次の動きを見ます。横へ引かれ、一気に消し込むところで合わせる準備をしておきます。

掛かったら竿を立て、魚が網へ向かう方向と逆の中央側へ誘導します。糸だけで突っ込みを止めず、竿の曲がりとドラグで受けます。

水面まで寄ったらタモへ。首を振られる前に頭をタモへ向けて取り込む段取りを作ります。

## 食いが渋いとき

アタリが遠いときは、むきエビからオキアミ、練りエサなどへ替え、タナも探り直します。エサの種類だけで決めず、付ける大きさと糸の張りも一つずつ見直します。

### エサを替え、硬さも見直す

エサだけ取られるなら、塩締めしたむきエビやボイルオキアミで、針に残りやすいものを試す手があります。硬くしすぎたものは小さく切り、口に取り込みやすくします。

冬は麩・パン・コーンなど軽いエサへ反応が変わることがあります。経験則として試す選択肢にとどめ、季節でエサの順番を固定せず、当日のアタリを見て選びます。

### 糸を引っ張り続けない

小さなアタリの後に食い込まないなら、竿先を少し送って張りを弱めます。大きく糸をたるませるより、水面の糸の動きを追える状態に整えます。

底寄りで警戒心の強い魚の狙い方は、[クロダイのタナと仕掛け](/tactics/fish-strategy/chinu/)も参考になります。

### ゼロウキは上級者の選択肢

浮力の小さなゼロウキでエサを自然に沈める釣りは、上級者の選択肢です。
アタリを道糸の横移動や張りで読むため、まずは通常のウキでタナとエサの反応をつかみ、扱える範囲で試します。

## 持ち帰りと臭みの抑え方

メジナが臭いかどうかは処理によって変わり、臭みを抑える基本は血抜きと背骨まわりの血合い（背わた）の洗浄です。海上釣り堀のメジナは配合飼料で育つため、磯の藻類由来の臭みが出にくいとされますが、持ち帰った魚も丁寧に下処理します。

### 血抜きから、背わたの洗浄まで

1. 釣ったら脳天締めをする
2. エラを切って血を抜き、冷やして持ち帰る
3. 鱗と内臓を取り、三枚におろす
4. 背骨まわりの血合いを、調理用の歯ブラシと流水で洗い落とす
5. ペーパーで水気を取る

ブラシは身を強くこするためでなく、残った血合いを落とすために使います。洗った後は水気を残さず、調理する分と保存する分へ分けます。

締めと保存の考え方は、[マダイの持ち帰りと料理](/tactics/fish-strategy/madai/gourmet/)でも紹介しています。

### 寒グレは、薄造りやしゃぶしゃぶに

冬の11〜2月のメジナは寒グレと呼ばれ、脂がのる季節です。薄造りに柚子胡椒を添えたり、しゃぶしゃぶにしたりすると、白身を食べ分けられます。

冷蔵庫で1日置くと身が締まり、薄く切りやすくなります。日数だけで生食の可否を判断せず、処理と保冷の状態に合わせて調理します。

| 食べ方 | 選び方 |
|---|---|
| 薄造り | 薄く切れる身を、柚子胡椒やポン酢と合わせる |
| しゃぶしゃぶ | 大きめの魚を薄切りにし、出汁で火を通して楽しむ |
| 煮付け | 下処理した身を煮汁で仕上げる |
| 唐揚げ | 小型の魚を切り分けて使う |

## よくある質問

### メジナの仕掛けはどれくらい細くしますか？

ハリス1.5〜2号・グレ針4〜6号が目安です。施設のおすすめに合わせ、エサを自然に沈められる軽さへ整えます。

### エビに反応しなくなったら？

オキアミや練りエサへ替え、タナと付ける大きさも見直します。冬は麩やパンなどに反応が変わることもあります。

### 掛けた直後、網に擦れて切れます

竿を立てて引きを受け、魚が向かう網と逆の中央側へ誘導します。ドラグはやや緩めにし、竿の弾力を使って突っ込みをいなします。

### 海上釣り堀のメジナも臭いのですか？

臭みは処理によって変わります。血抜きをし、背骨まわりの血合いを洗い流して水気を取ることが、調味料を加える前の大切な工程です。

### 小型のメジナはどう食べますか？

煮付けや唐揚げが選択肢です。薄く切る料理にこだわらず、大きさに合わせて食べ方を選ぶと使いやすくなります。

## まとめ

メジナが目当てなら、出発前に次の準備をしておきます。

1. 施設表から行き先を選び、狙うエリア・放流予定・冬の営業を調べる
2. 小さめのエサと施設のおすすめに合う仕掛けをそろえる
3. 血抜きと保冷、帰宅後の背わた洗浄の段取りを用意する

網際へ走る魚を中央へ向け、タモに収めたら、丁寧に冷やして持ち帰る。薄造りや温かな煮付けまで、引きの強いメジナを一日のごちそうとして楽しめます。
