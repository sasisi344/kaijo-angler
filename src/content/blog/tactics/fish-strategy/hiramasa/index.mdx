ヒラマサは海上釣り堀で放流している施設が限られる青物で、掛かった直後の走りがブリより速く、網に向かって突っ込むので切られやすい魚です。ドラグはブリより少しゆるめにして滑らかに出るようにし、最初の走りを指で押さえながら竿でいなすのが基本です。

このページでは、ブリ・カンパチとの違い、基本情報、ヒラマサを対象魚にしている施設、釣り方、ドラグ設定と指ドラグ、網際（イケスの網のすぐそば）での取り込みの順にまとめます。ヒラマサを掛けたことがある人は、ドラグ設定の節から読めます。

---

## ヒラマサとは（ブリ・カンパチとの違い）

ヒラマサはブリ・カンパチと並ぶ「青物三兄弟」の一角で、三者の中で走り出しがもっとも速いとされる魚です。ブリは重く持続する引き、ヒラマサは掛けた直後の一直線の走りが、体感の違いです。

天然では黒潮が流れる温暖な外洋を好み、小魚の群れを追って猛スピードで突撃する捕食スタイルから「海のスプリンター」と呼ばれます。養殖された魚でも<strong>「高速で動くものを追う」捕食本能</strong>は残っていて、活きエサの速い動きに反応します。

<strong>難易度：★★★（上級）</strong>

海上釣り堀でヒラマサを放流している施設は限られますが、入っていればイケスでいちばん手ごわい相手です。ブリの引きと攻略は「[海上釣り堀のブリ（ワラサ・メジロ）攻略](/tactics/fish-strategy/buri/)」で読み比べられます。

| 比較項目 | ブリ | カンパチ | ヒラマサ |
|----------|------|----------|----------|
| <strong>走り出しの速さ</strong> | 速い | やや速い | <strong>最速とされる</strong> |
| <strong>引きのパターン</strong> | 直線的な走り（重く持続する） | 底突っ込み＋横走り | <strong>掛けた直後の一直線の走り</strong> |
| <strong>タナの傾向</strong> | 中層〜底 | 底付近 | <strong>表層〜中層</strong> |
| <strong>体型の特徴</strong> | 紡錘形 | 側扁形 | <strong>細長く流線型</strong> |
| <strong>捕食スタイル</strong> | 追い食い | 待ち伏せ寄り | <strong>追い食いの極致</strong> |

ヒラマサは網に向かう勢いも強く、イケスの中でも<strong>浅めのタナを速く駆け抜ける</strong>のが特徴です。ブリと同じ感覚で構えていると、この最初の走りに対応できません。

### 掛けた直後に見分ける

同じイケスにブリ・カンパチ・ヒラマサが混ざっているときは、掛けた直後の走り方で見当がつきます。

| 掛けた直後の走り | 見当をつける魚 | 対応 |
|---|---|---|
| 浅いタナで一直線の爆発的な走り | ヒラマサ | ドラグをやや緩めて最初の走りを出し、指ドラグの準備 |
| 底へ向かって重く引っ張る | [カンパチ](/tactics/fish-strategy/kanpachi/) | 底突っ込みを竿で止める |
| 速いが曲線的に走る | ブリ | ドラグで受け流して長めのやり取り |

釣り上げてからの見分けは、次の2点が一般によく使われる目印です。

- <strong>上あごの角が丸い</strong>のがヒラマサ（ブリは角ばる）
- 体側の<strong>黄色い帯がはっきり</strong>しているのがヒラマサ

## 基本情報まとめ

ヒラマサの基本は、表層〜中層のタナ、元気な活きアジ、ブリより少しゆるめのドラグの3点です。数値は目安なので、仕掛けの号数は施設のおすすめに合わせます。

| 項目 | 内容 |
|------|------|
| <strong>推奨タナ（棚）</strong> | 表層〜中層（ブリよりも上のタナを意識） |
| <strong>活性が上がりやすい時間</strong> | 放流直後（15〜30分が最大のチャンスとされる）・朝マズメ・潮の変わり目 |
| <strong>おすすめシーズン</strong> | 春〜初夏・秋（水温20〜26℃が目安） |
| <strong>定番エサ</strong> | 活きアジ（やや大きめ）、活きイワシ |
| <strong>代替エサ</strong> | 死にイワシ（動かす）、カツオの切り身（スレた個体に）、シラサエビの房掛け（表層） |
| <strong>推奨ハリス</strong> | フロロカーボン5〜7号（最初の走りに耐える強度） |
| <strong>推奨針</strong> | 伊勢尼14〜16号の大型針 |
| <strong>道糸・竿</strong> | 道糸はPE4号以上またはナイロン12号以上。竿は青物専用の強靭なもの |
| <strong>ドラグ</strong> | ブリより少し緩め。指で引いてスムーズに出る設定（完全ロックは厳禁） |

※ ハリスと針の号数は、施設が勧める仕掛けや貸し出しの仕掛けがあればそれに合わせます。

## 釣り方の基本

ヒラマサは表層〜中層を回る魚なので、ブリの底タナのまま待たず、元気な活きアジを浅めのタナへ届けるのが基本です。

### タナは浅めから

1. ウキ下を<strong>水深の1/3〜半分</strong>（2〜4m）にセットする
2. アタリがなければ浅め（1〜2m）も試す
3. 放流直後は表層付近で活性が高いことが多い
4. 活きエサが元気に泳いでいるタナを目安にする

マダイの底タナのままでは、ヒラマサの泳ぐ層にエサが届きません。タナの考え方は「[海上釣り堀のタナの基本](/column/trivia/tana-basics/)」にまとめています。

### 活きエサは背掛けで

- <strong>活きアジ（大きめ・元気なもの）</strong>：背掛けで投入し、着水後すぐに元気に泳ぎ始めるかを見る
- <strong>活きイワシ</strong>：泳ぎが速く捕食本能を刺激する。弱りやすいのでこまめに交換する
- <strong>鼻掛けより背掛け</strong>：ヒラマサが追いかける向き（後方）に針が来るようにする

### エサは元気なうちに替える

ヒラマサは目が良く、弱ったアジを見切るとされます。アタリがなくても、<strong>5〜10分ごとに活きアジを替える</strong>つもりでいると、常に元気な個体を水中に置けます。

- アジは背ビレの付け根に浅く刺す。内臓に触れる深さだと弱りやすい
- バケツはエアポンプで酸素を保ち、夏は凍らせたペットボトルで水温の上がりすぎを防ぐ
- 素手で握らず、タモか濡らした手で優しくすくう（体温でアジが傷む）
- オモリは軽め（0.5〜1号）にする。重いとアジが不自然な姿勢になり、見切られやすい

活きアジに反応しない個体には、カツオやイワシの切り身を中層で漂わせたり、表層でシラサエビを房掛けにしたりする手があります。ただし、使えるエサは施設のルールで違うので、事前に聞いておきます。

### 追いかけず、回遊を待ち伏せる

ヒラマサはイケスの網際を回ることが多いとされ、高速で動く魚を追いかけるより、減速しやすいコーナーなどで待つほうが仕掛けを届けやすくなります。

1. 網から少し離して、仕掛けを<strong>真上から垂直に降ろす</strong>（投げると網に当たる）
2. アジが一カ所で暴れる状態にしておく（これがいちばんのアピール）
3. 水面の波紋や背ビレが見えたら、手を触れずに待つ
4. 偏光グラスをかけて、ヒラマサの通るルートとタナを観察する

### 動かすなら速く・大きく

アタリがないときは、通常のブリ狙いより速く大きな誘いを試します。竿を大きく振り上げて活きエサを驚かせる、エサを回収してすぐ打ち返す、といった速い動きが、ヒラマサの追う本能を刺激します。ゆっくりした誘いは効きにくいとされます。

## ドラグ設定と指ドラグ

ヒラマサのドラグは、ブリより少しゆるめの「指でラインを引いてスムーズに出る」設定にして、完全にはロックしません。最初の走りは竿を立てて弾力で受け、網に向かうときだけ、スプールに指を当てる指ドラグで足し引きします。

ヒラマサは「力で勝負する魚」というより、「速さをいなす魚」です。ブリと同じ感覚でドラグを締め込むと、最初の走りでハリスが先に切れます。逆にゆるすぎると、ラインが出すぎて他の人とオマツリになります。

### 掛けたら、まず声を出す

1. <strong>「青です！」と大きな声で周囲に知らせる</strong>。ヒラマサの走りは横方向にも広がるので、隣の人に仕掛けを上げてもらう時間をつくる
2. 竿を立てて、竿全体の弾力で最初の衝撃を受ける。足を肩幅に開き、体全体で引きを受ける
3. 止めようとせず、ドラグに任せてラインを出す
4. 走りがゆるんだところで、少しずつ巻き取る

最初の走りのあとに、ドラグを一度に締め込まないことがコツです。魚の走りを見ながら、段階的に締めていきます。10kg前後の大型を掛けたときほど、最初の走りが網際まで届くことがあるので、ここでの準備が効きます。

### ヒット前に見ておくところ

| 確認項目 | 見方 | OKの目安 |
|---|---|---|
| ドラグ | 指でラインを引っ張る | スムーズに出る・止まらない |
| ハリス | 指の爪でこする | 引っかかりがない |
| 竿先・ガイド | 竿先を見る | 穂先やガイドに異常がない |
| リール | 空回しする | 引っかかりなく回る |
| 足元 | 周囲を見る | 転倒や絡まりの元がない |

### 切られるのは、ドラグより先にハリスと結び目

投入前に指でドラグを引いてスムーズに出ることを確かめ、ハリスを爪でなぞると、先のほうにざらつきがある。次の一投の前に結び直すかどうかで、ヒラマサを掛けたあとの結果が変わります。

最初の走りで一気にラインが出るとき、いちばん弱い所に力が集まります。傷の入ったハリスや、締まりきっていない結び目が、その弱い所です。

選ぶ条件は、<strong>施設のおすすめに合わせた号数（目安は5〜7号）で、結びを整えやすいしなやかな糸質であること</strong>です。[シーガー公式](https://www.seaguar.ne.jp/lineup/fcharisu/fc_5.html)では、グランドマックスFXをしなやかさを加えたフロロカーボンハリスと案内しています（2026年11月9日確認）。その条件で選ぶ製品の一つです。

<TackleCard id="tackle/seaguar-grandmax-fx" placement="hiramasa-index" reason="ヒラマサの最初の走りに備えて、ハリスを自分で結ぶ人へ。傷を見つけたその場で結び直すとき、結び目が締まりやすいしなやかなフロロハリスです。" />

完成仕掛けを現地で買う人や借りる人は、仕掛けごと新しいものに替えれば、結び直す手間はありません。

### 指ドラグのやり方

指ドラグは、リールのドラグに釣り人の指先の感覚を足す方法です。スプールに指を当てて摩擦を加え、ドラグの効きを一時的に強めます。指を離せば、すぐ元のドラグ設定に戻ります。

1. リールのスプールエッジに、人差し指か親指の<strong>腹</strong>を軽く当てる
2. 摩擦の強さを変えて、ドラグの効きを一時的に足し引きする
3. 指を離すと、ドラグが元の設定に戻る

| 指ドラグの強さ | 指の当て方 | 使う場面 |
|---|---|---|
| 軽い | 軽く触れる程度 | 全力で走っている最中の軌道修正 |
| 中くらい | 指の腹で軽く押さえる | 網際に近づいたとき |
| 強い | 指でしっかり押さえる | ヒット直後の暴走を止めたいとき |

押さえるというより、<strong>触れる</strong>くらいの感覚から始めます。強く押さえすぎると、ラインに負荷がかかって切れます。家でも、ラインを巻いたリールを持ち、もう一方の手でラインを引きながら、「触れる→軽く押さえる→しっかり押さえる」の3段階を指に覚えさせておけます。

### 網際で反転させる

ヒラマサが網へ向かって走り出したら、正面から引っ張っても止まりません。竿の向きでラインの角度を変え、魚の頭の向きを変えさせます。

1. 網のほうへ走り出したら、<strong>竿を中央側へ大きく倒す</strong>
2. ラインの角度が変わり、ヒラマサの頭の向きが変わる
3. 指ドラグで一瞬ブレーキをかけ、「進めない」と感じさせる
4. 向きを変えた瞬間に、素早く巻き上げる

竿を倒しても向きが変わらないときは、倒す角度が足りない可能性があります。水面近くまで倒すと、向きが大きく変わります。

### 引きが軽くなったら寄せどき

最初の走りが落ち着いたら、竿を立てながら巻いて魚を浮かせる動作（ポンピング）を繰り返します。急に引きが軽くなるのは、魚が疲れてきたサインです。ここで焦って強引に巻くと、バラしやすくなります。

## 取り込み

網際まで寄せたら、ネットに入るまで気を抜かないのが取り込みの基本です。上がったあとは、口をグリップでつかみ、素手で押さえません。

ヒラマサは、水面直下で最後にもう一度走ることがあります。ネット担当の人に合図を出して、竿を持つ人と息を合わせます。

タモに入ったヒラマサは、足元で尾を打ち続けます。口にはまだ針が残っています。素手で体を押さえると、体温で身が傷み、手を針に近づけることにもなります。

そこで手元に欲しいのは、<strong>魚の下あごをしっかりつかんで固定でき、海水で錆びにくい素材</strong>のグリップです。アルミ製のこのグリップは、その条件に合う一つです。

スタッフが針外しを手伝う施設なら、その日は頼めば、自分でグリップを持たなくても取り込めます。

## 季節と状況

ヒラマサのシーズンは、春〜初夏と秋です。適水温は20〜26℃が目安で、ブリより高めとされます。

| 季節 | ヒラマサの動き | 狙い方 |
|---|---|---|
| 春（4〜6月） | 水温が上がり、表層近くに上がってくる。最大のチャンス | 浅めのタナを中心に |
| 夏（7〜9月） | 高水温でも活性を保つ。盛夏は早朝が中心。水温が28℃を超えると深場に落ちることがある | 朝一（6〜9時）に集中し、それ以降は他の魚へ切り替える |
| 秋（10〜11月） | 荒食いの時期。大型が出やすく、走りもいちばん強い | 最初の走りに備えてドラグとハリスを整える |
| 冬 | 活性が落ち、深めのタナに落ちることが多い | 深めのタナを試す。カツオの死にエサも手になる |

時間帯では、<strong>放流直後の15〜30分</strong>が最大のチャンスとされ、次いで潮の変わり目です。

海面が少し荒れている日や、風が少しある日は、活性が上がる傾向があります。反対に、放流数が少ない日、水温が急に変わった日、低気圧が通ったあとは、ヒラマサの活性が落ちやすいとされます。こうした日は、スタッフに「今日のヒラマサの活性」を聞いてみるのが、いちばん早い情報収集です。

## よくある失敗と質問

<strong>Q：放流されているはずなのに、全くアタリがない</strong>
→ タナが深い可能性が高いです。ブリ用の底タナのままでは、ヒラマサに届きません。中層〜浅めに変えて、活きアジの動きを見ます。

<strong>Q：ヒット直後に、一瞬でハリスが切れた</strong>
→ ハリスが細すぎるか、ドラグが締まりすぎています。ハリスの太さを施設のおすすめに合わせ、ドラグを指で引いてスムーズに出る設定へ戻します。ハリスの傷や結び目も見直します。

<strong>Q：指ドラグで止めたら、ラインが切れた</strong>
→ 押さえる力が強すぎます。指でスプールを「押さえる」のではなく「触れる」ところから始めます。

<strong>Q：最初の走りは耐えたのに、2回目の走りで外れた</strong>
→ 疲れてきたと思ったところで、焦って強引に巻くとバラしやすくなります。引きが軽くなっても、水面直下で最後にもう一度走ることがあるので、ネットに入るまで竿を立てて弾力を残します。

<strong>Q：魚が見えているのに食わない</strong>
→ 活きアジが弱っている可能性があります。仕掛けをいったん回収し、新しいアジに替えて再投入します。

<strong>Q：隣の人がヒラマサを掛けた。自分の仕掛けはどうする</strong>
→ すぐにラインを上げるか、ラインを全部ゆるめます。ヒラマサは横方向にも走るので、絡まりやすくなります。隣の人の取り込みが終わるまで待つのが、お互いの釣りを守る方法です。

## まとめ：ヒラマサを掛けたら、ドラグと指で受ける

ヒラマサ攻略のポイントは3つです。

1. <strong>表層〜中層のタナに、元気な活きアジを届ける</strong>
2. <strong>ドラグはブリより少しゆるめにして、最初の走りは指ドラグと竿でいなす</strong>
3. <strong>掛けたらすぐ「青です！」と声を出し、網に入れるまで気を抜かない</strong>

> <strong>行くと決めたら</strong>
>
> 1. 上の表から、行ける範囲でヒラマサを対象魚にしている施設を選び、予約のときに放流の予定を聞く
> 2. 前の晩に、ドラグを指で引いてスムーズに出るか、ハリスに傷がないかを見る
> 3. 大型青物の基本のやり取りは、「[ブリの攻略](/tactics/fish-strategy/buri/)」と読み比べる

網際で穂先が絞られ、ドラグが鳴り、指先にスプールの回りを感じながら、竿を中央側へ倒す。ヒラマサがふっと向きを変えて浮いてくるところが、この釣りの山場です。
