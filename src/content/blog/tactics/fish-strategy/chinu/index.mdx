海上釣り堀のクロダイは、底ぎりぎりにいて警戒心が強く、マダイより細いハリスと小さめのエサで、仕掛けの違和感を減らして食わせる魚です。持ち帰ったら釣ってすぐ締めて血を抜き、その日のうちに内臓を取ると、洗いや刺身でも臭みを抑えられます。

底へエサを届け、ウキがわずかに横へ動くのを待つ。小さな変化が竿の重みに変わる瞬間が、この魚を狙う面白さです。取り込んだ後の処理まで準備しておけば、持ち帰る白身も楽しみになります。

## クロダイとは

クロダイはチヌとも呼ばれ、特に関西で親しまれている魚です。マダイの外道として扱うだけでなく、警戒心の強さに合わせて仕掛けを組み、主役として狙えます。

難易度の目安は中級。音や振動、仕掛けの抵抗に敏感なので、静かにエサを入れ、魚が食い込むまで引っ張らないことが大切です。

雑食性があり、オキアミのほかサナギやコーンも定番です。一つのエサに頼らず、当日の反応に合わせて替える余地があります。

## 基本情報まとめ

クロダイは底から10〜20cmを基準に、小さめのエサと細めのハリスで狙います。号数は目安として、施設のおすすめや同じイケスの魚のサイズに合わせます。

| 項目 | 内容・目安 |
|---|---|
| タナ（エサを置く深さ） | 底ぎりぎり。底から10〜20cmが基準 |
| 狙う時間 | 朝マズメ・音や振動の少ない静かな時間 |
| シーズン | 春〜秋。冬は底付近で置き釣り |
| 定番エサ | 小さめで新鮮なオキアミ |
| 替えのエサ | サナギ、コーン、甘エビのむき身 |
| ハリス | フロロカーボン1.5〜2号が目安 |
| 針 | クロダイ用の針3〜5号が目安 |
| ドラグ | マダイと同程度、やや緩め |
| 釣りの要点 | 底の位置を測り、糸の張りすぎと大きな物音を避ける |

## タナ: 底ぎりぎりと、ハワセ

底ぎりぎりの釣りは、エサを底から10〜20cm浮かせる考え方です。一方のハワセは道糸を底に這わせて抵抗を減らす釣り方で、底が網のイケスでは施設の指示する深さを超えない範囲で扱います。

### まず、底から少し浮かせる

釣り座の底の位置を測り、そこからエサが少し上に来るようにウキ下を決めます。ウキ下とはウキから針までの長さで、エサを入れる深さの基準です。

1. 施設が指定する深さと、底網の位置を把握する
2. エサが底から10〜20cm上に来るタナへ合わせる
3. アタリがなければ、底網へ掛けない範囲で少しずつ調整する

潮で仕掛けが斜めになると、設定した長さと実際のエサの位置に差が出ます。流れや投入位置が変わったら、深さだけでなく仕掛けの傾きも見ます。

底取りの具体的な考え方は、[海上釣り堀のタナの基本](/column/trivia/tana-basics/)へ。<strong>針を網の底より深く出さない</strong>ことが先です。

### ハワセは、糸の張りを減らす別の釣り方

ハワセは、底に糸の余裕を持たせ、魚がエサを口にしたときの抵抗を減らす方法です。エサを浮かせて待つ通常の底釣りと、同じ設定として扱わないようにします。

天然の海底を狙う釣りの感覚で、イケスでもウキ下を長く足すと針が網に掛かります。施設の指示を超えて長くするのではなく、その範囲で扱える場合の応用と考えます。

| 釣り方 | エサ・糸の置き方 | 見るところ |
|---|---|---|
| 底ぎりぎり | エサを底から少し浮かせる | ウキの沈み・横移動 |
| ハワセ | 道糸を底に這わせ、張りを減らす | 糸フケの動き・ウキの横移動やシモり |

シモりとは、ウキが普段より少し深く沈む動きです。ハワセではウキの消し込みだけを待たず、糸が横へ動き始める変化にも目を向けます。

### 流れで位置を保てないとき

表層と底で流れの向きが違うと、ウキとエサの位置がずれます。ハワセに固執せず、通常の底釣りへ戻してタナを保ちやすい状態から探り直します。

私なら、最初は底から少し浮かせる釣りでアタリを探します。深さを把握してから糸の張りを調整するほうが、何を変えて反応が出たかを追いやすいためです。

## エサと仕掛け

エサは小さめのオキアミを基本に、サナギ・コーン・甘エビのむき身を使い分けます。ハリス1.5〜2号と軽い針を目安に、仕掛けがエサを不自然に引っ張らない組み合わせを選びます。

### 小さく付け、反応を見て替える

| エサ | 付け方・試す場面 |
|---|---|
| オキアミ | 新鮮で小さめのものを使う基本のエサ |
| サナギ | オキアミへの反応が遠いときの定番の替えエサ |
| コーン | 一粒ずつ付け、エビ類との反応の違いを見る |
| 甘エビのむき身 | 柔らかさを生かし、小さく整えて付ける |

雑食性でも、何を入れても同じように食うわけではありません。同じエサでアタリが遠ければ、種類や付ける大きさを変え、反応の違いを探ります。

マダイばかり掛かる場合も、タナを底へ寄せ、サナギやコーンを試す手があります。エサだけで魚種を選び切ろうとせず、底の位置と組み合わせます。

### ハリスと針は、エサの落ち方まで見る

太いハリスや重い針で食い込まないなら、施設の推奨範囲で細め・軽めへ寄せます。クロダイ用の針3〜5号を基準にし、食い渋りではグレ針などの軽量針も選択肢です。

軽い針へ替えると、エサの落ち方を自然にしやすくなります。号数だけを小さくし続けず、針とエサの重さの組み合わせを見ます。

マダイとの狙い方の違いは、[海上釣り堀のマダイの釣り方](/tactics/fish-strategy/madai/)と読み比べると、タナと仕掛けを選びやすくなります。

### 撒き餌・ダンゴは施設の規則に従う

撒き餌や紀州釣りのダンゴは、施設の規則に従います。針に付けるエサと撒き餌も分けて扱い、使えるかどうかを一律には判断しません。

イケスで釣るときは、底網へ針を掛けない範囲で、小さなエサを自然に届けることから始めます。

## アタリの取り方と取り込み

クロダイのアタリは、ウキの小さな沈みや横移動、穂先のわずかな動きとして出ます。最初の変化で引き抜かず、引き込みが続くところでゆっくり竿を起こし、違和感を与えないように掛けます。

### モゾモゾの次の動きを待つ

| 見える動き | 対応 |
|---|---|
| ウキが小さく震える | エサを引かず、その後の変化を見る |
| 少し沈んで止まる | 糸を張りすぎず、続く動きを待つ |
| ウキが横に動く | 食い込みと糸の張りを見ながら竿を起こす |
| 糸フケが横へ動く | 余分な糸が残りすぎないようにして重みを捉える |

糸フケは、張りきらずに余っている糸のことです。大きくたるませると合わせが届きにくいので、抵抗を減らしつつ魚の動きを追える程度に保ちます。

### 静かな釣り座を保つ

足音や道具を置く音を抑え、投入時も仕掛けを水面へそっと入れます。反応がないからと大きく竿を動かし続けるより、エサとタナを一つずつ替えて様子を見ます。

### 掛けたら、竿の曲がりで受ける

ドラグはマダイと同程度のやや緩めを目安にし、細いハリスへ急な負荷を掛けないようにします。走っている間は竿の曲がりで受け、引きが落ち着いたところで巻き取ります。

取り込みはタモへ誘導します。次の投入前には、ハリスと針に傷みがないかを見ます。

## 季節と時間帯

海上釣り堀のクロダイは春〜秋を中心に、朝や静かな時間を狙います。冬は底付近で静かに待つ置き釣りを軸にし、エサを動かしすぎないようにします。

| 季節・条件 | 狙い方 |
|---|---|
| 春〜秋 | 底ぎりぎりのタナで、エサの反応を探る |
| 夏 | 早朝の反応を意識する |
| 冬 | 底付近で置き釣り。打ち返しを急がない |
| 音や振動の少ない時間 | 小さなアタリを見ながら静かに待つ |

天然のクロダイでは春の乗っ込みが知られますが、海上釣り堀では当日の放流魚の反応を見て組み立てます。季節だけで食いを決めず、タナ・エサ・静けさを順に整えましょう。

## 持ち帰りと臭みの抑え方: 洗いと刺身

クロダイの洗い・刺身の臭みを抑えるには、釣ってすぐ締めて血を抜き、その日のうちに内臓を取ることが基本です。洗いは薄切りの身を氷水にさっと通す料理で、下処理を済ませた魚の引き締まった食感を楽しめます。

### 締め・血抜き・内臓処理を続けて行う

1. 釣り上げたら脳締めする
2. エラを切り、海水で血を抜く
3. その日のうちに腹を開いて内臓を取る
4. 腹の中を洗い、水気を取って冷やす

内臓を傷つけないように取り出し、腹の中まで丁寧に洗います。帰宅後の味付けより先に、釣り場から冷やして運ぶ段取りを作っておきます。

締めや保存の考え方を詳しく読みたいときは、[マダイの持ち帰りと料理](/tactics/fish-strategy/madai/gourmet/)も参考になります。

### クロダイの洗いの作り方

洗いは、刺身用に皮を引いた身を薄切りにし、氷水でさっと締めて作ります。香りを調味料で隠す前に、血抜きと内臓処理を済ませておくことが大切です。

1. 下処理した身を薄く切る
2. 氷水へさっと通す
3. 水気をしっかり取り、皿へ盛る
4. ポン酢ともみじおろし、または梅肉を添える

氷水へ長く漬け込むのではなく、通した後の水切りまで進めます。コリッとした食感を楽しみたいときの食べ方です。

### 刺身と、翌日以降の食べ方

家庭では冷やして1〜2日置くと旨味が増すとされます。水気をペーパーで取り、ラップで包んでチルド室へ入れ、3日以上保存するなら冷凍へ回します。

この日数は、生食できる期間を保証するものではありません。処理と保冷の状態に合わせて、刺身にするか、火を通すかを選びます。

| 食べ方 | 楽しむところ |
|---|---|
| 洗い・刺身 | 白身の食感を、ポン酢や梅肉と合わせる |
| 塩焼き | 身と皮を焼き上げる定番 |
| 煮付け | 切り身を煮汁と合わせる |
| 潮汁 | 頭や中骨などのアラを使う |
| 香草焼き | ローズマリーやタイムの香りを添える |

同じ底寄りの魚でも、持ち帰りの要点は少し違います。[メジナの釣り方と臭みを抑える処理](/tactics/fish-strategy/mejina/)では、背骨まわりの血合いの洗浄を紹介しています。

## よくある質問

### タナは底に付けるのですか？

基本は底から10〜20cm浮かせます。糸を底に這わせるハワセとは分け、イケスでは施設の指示する深さを超えず、底網へ針を掛けないようにします。

### マダイばかり掛かるときは？

タナを底ぎりぎりへ寄せ、サナギやコーンなど別のエサを試します。小さく付ける工夫と、静かな投入も合わせて見直します。

### 小さなアタリで空振りします

最初の震えで引き抜いている可能性があります。続く引き込みを待ち、糸の余裕を整えてからゆっくり竿を起こします。

### 撒き餌やダンゴを使ってもよいですか？

施設の規則に従います。イケス・筏・海釣り公園で同じ扱いとは考えず、指定されたエサと釣り方に合わせます。

### クロダイの刺身の臭みを取るには？

釣った直後の締め・血抜きと、当日の内臓除去が基本です。皮を引き、腹の中を洗って水気を取り、冷やして持ち帰ります。

### 洗いにするときのコツは？

下処理した身を薄く切り、氷水にさっと通してから水気をしっかり取ります。ポン酢や梅肉を添えると、引き締まった白身をさっぱり楽しめます。

## まとめ

次の釣行では、底の位置と持ち帰りの準備を先に整えます。

1. 施設表からイケス・筏・公園を選び、狙うエリアと使うエサを決める
2. [タナの基本](/column/trivia/tana-basics/)を読み、底網に掛けない深さで小さなエサを届ける
3. 血抜きと保冷、帰宅後に内臓を取る段取りを用意する

静かな水面でウキが横へ滑り、竿に重みが乗る。その一匹を丁寧に冷やして持ち帰り、洗いと潮汁にすれば、釣り場から食卓までクロダイを楽しめます。
