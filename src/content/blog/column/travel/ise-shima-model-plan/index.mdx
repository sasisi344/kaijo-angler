## おすすめの1泊2日モデルコース

伊勢志摩は「釣り＋伊勢神宮参拝」が最も人気の組み合わせです。1日目に釣行、2日目に観光を入れると渋滞も分散できます。

| 時間 | <strong>1日目：釣行</strong> | <strong>2日目：伊勢神宮＆観光</strong> |
| :--- | :--- | :--- |
| <strong>早朝</strong> | 選んだ施設で集合（6:00〜7:00） | 伊勢神宮・外宮参拝 |
| <strong>午前</strong> | 釣り（午前放流タイムが最高潮） | 伊勢神宮・内宮参拝、五十鈴川で手を清める |
| <strong>昼食</strong> | 海女小屋で豪華磯焼き、またはBBQ（トリトン） | おかげ横丁で伊勢うどん・赤福 |
| <strong>午後</strong> | 施設終了後、鳥羽・志摩の温泉宿へ | おはらい町で食べ歩き・土産 |
| <strong>夕刻</strong> | 宿で釣果を懐石料理・お刺身で | 伊勢ICより帰路へ |

<strong>宿の選び方</strong>：鳥羽・賢島エリアに高級旅館が集中。予算を抑えるなら伊勢市内のビジネスホテル（内宮まで車10分）も実用的です。

## グルメ：伊勢志摩で必ず食べたい3品

### 海女小屋体験（伊勢海老・あわび）

鳥羽・志摩エリアの海女小屋では、伊勢海老やあわびを炭火で焼いてくれる体験が大人気です。夏〜秋シーズンは予約必須。価格は海産物次第（伊勢海老は時価）で変動します。

### てこね寿司

志摩地方の漁師飯。カツオまたはマグロを甘辛い醤油ダレに漬け、酢飯と合わせた丼スタイル。釣り後のランチに最適で、1,000〜1,500円台が相場です。

### 伊勢うどん

太くて柔らかい麺に濃厚な黒タレ。見た目より辛くなく、子供も食べやすい。おかげ横丁に複数の名店があります。

## 伊勢神宮参拝：釣りと組み合わせるコツ

- <strong>外宮→内宮の順</strong>が正式。外宮は所要30分、内宮は1時間以上みておくと余裕あり
- <strong>五十鈴川の御手洗場</strong>：内宮近く。手を清める場所として有名で、空気が変わる体験ができます
- <strong>おかげ横丁</strong>：参拝後の食事・土産に最適。混雑は昼ピーク。朝8〜9時の外宮参拝後に内宮へ向かうと比較的空いています
- <strong>車の場合</strong>：内宮の駐車場は混雑しやすい。B4・B5駐車場（有料）を使うか、おはらい町付近の民間駐車場を利用

## よくある質問（FAQ）

<strong>Q1. 電車だけで施設まで行けますか？</strong>  
最寄り駅から施設まで徒歩圏外の施設がほとんどです。駅レンタカーまたはタクシーが必要です。詳細は▶ [伊勢志摩アクセスガイド](/column/travel/access/ise-shima-access-guide)

<strong>Q2. 子供連れで楽しめる施設はどこですか？</strong>  
トリトン・正徳丸・佐助屋はスタッフのサポートが手厚く、設備も整っています。上の比較表で「子連れ ○」の施設を参照してください。

<strong>Q3. 大阪・名古屋から日帰りは可能ですか？</strong>  
可能ですが、集合時間が早朝6〜7時の施設が多いため、大阪発は3〜4時台、名古屋発は4〜5時台の出発が現実的です。渋滞の読み方も含め▶ [アクセスガイド](/column/travel/access/ise-shima-access-guide) で詳しく解説しています。

<strong>Q4. 釣り道具を持っていなくても大丈夫ですか？</strong>  
竿・仕掛けのレンタルに対応している施設がほとんどです。各施設記事の「基本情報」欄を確認してください。

<strong>Q5. 海上釣り堀って初心者でも釣れますか？</strong>  
放流魚が高密度のため、ほぼ全員が1匹以上釣れます。当日の流れや持ち物は▶ [初めての海上釣り堀ガイド](/tactics/beginner/first-fishing-pond) で詳しく解説しています。
