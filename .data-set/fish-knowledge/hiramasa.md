## 3. 釣り方

### 3.1 基本 — 【記事】

- 高速で動くものを追う捕食本能。バタバタと激しく動く活き餌が最も効く。弱ると食い気が落ちる
- 活きアジは背掛け（追いかける方向＝後方に針が来るように）。活きイワシは弱りやすいのでこまめに交換
- ブリの底タナのままでは届かない。浅めを意識する
- 風や波が少しある日は活性が上がる傾向

### 3.2 壁際・コーナー待ち伏せ — 【記事】intermediate

- ヒラマサはイケスの網際50cm以内を高速で巡回するとされ、追いかけず、コーナーなど減速する場所で待つ
- 仕掛け位置の目安: コーナーから水平30〜50cm、水面から1.5〜3m。真上から垂直に降ろす（投げると網に当たる）
- アジが一カ所で暴れる状態が最大のアピール。気配（波紋・背ビレ）があれば手を触れず待機
- 光と影: 日向側は表層〜浅層、桟橋の影との境目、太陽を背にした逆光投入
- 偏光グラスで位置・タナ・減速ポイントを観察する

### 3.3 エサの鮮度管理 — 【記事】strategy

- 動体視力が鋭く、弱ったアジは見切られる。アジは5〜10分ごとに交換（アタリがなくても）
- バケツ管理: エアポンプ、夏は凍らせたペットボトルで15〜20℃、10Lに最大10匹、素手で握らない（体温でやけど）
- オモリは軽く（0.5〜1号、ノーシンカーは高活性時のみ）。重いと不自然な姿勢で見切られる
- 変化球: シラサエビ5〜7匹房掛けで表層シェイク、スレ個体にはカツオ切り身をスローリトリーブ（沈めて10〜20秒後に開始）
- 盛夏は朝一6〜9時に集中し、それ以降は他魚種に切り替え

### 3.4 超高速リアクション誘い — 【記事】index

- 通常のシャクりの2〜3倍の速さで大きく振る。速い打ち返し、竿先の小刻み高速振動

### 3.5 ファイト・ランディング — 【記事】

- ヒット直後は即座に「青です！」と大声で周囲に知らせる（走りは横方向にも広がる）
- ファーストランは止めず、ドラグで受け流す。竿は斜め45度前後（記事により45〜70度）
- 指ドラグ（サミング）: スプールエッジに指の腹を軽く当てる。網際に近づいたときに一時的にブレーキ
- 反転誘発: 網に向かったら竿を中央側へ大きく倒し、指ドラグで一瞬ブレーキ、向きを変えた瞬間に巻く
- 最初の1〜2分に最大出力を使い、その後は消耗。疲れたサインは急に引きが軽くなること。水面直下で最後の一走りがあるため最後まで油断しない
- 隣が掛けたら即ラインを上げるか緩める（横走りで絡みやすい）
- バックラッシュ対策: ドラグを緩める、親指で軽くサミング

### 3.6 魚種の見分け方 — 【記事】

- 掛けた直後: 浅いタナで一直線の爆発的な走り＝ヒラマサ、底へ重く＝カンパチ、速いが曲線的＝ブリ
- 外見: 腹鰭が胸鰭と同程度（ブリは胸鰭が腹鰭より長い）。側面の黄色いラインが直線的で鮮明

## 4. 季節・水温・時間帯

- 春（4〜6月）: 水温上昇で表層に上がる。最大のチャンス — 【記事】
- 夏（7〜9月）: 高水温でも活性を維持。盛夏は早朝のみ超高活性 — 【記事】
- 秋（10〜11月）: 荒食い。大型が出やすく走りも最強 — 【記事】
- 冬: 活性低下。タナが深くなる（3〜6m）。カツオの死にエサも有効 — 【記事】
- 水温別の回遊層: 15〜20℃は1〜4m、20〜25℃は0.5〜3m、25℃以上の朝一は超浅層 — 【記事】

## 7. アタリ・失敗パターン・FAQ — 【記事】

- 放流されているのにアタリがない → タナが深い。中層〜浅めに
- 一瞬でハリス切れ → ハリスが細い、ドラグが強すぎる
- オマツリ → ヒット時の声かけ遅れ
- 見えているのに食わない → 活き餌が弱い。いったん回収して10分後に新鮮なアジで再投入
- ヒラマサが来ない日 → 放流数が少ない、水温急変、低気圧通過後。スタッフに状況を聞く
