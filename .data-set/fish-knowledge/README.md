# 魚種別ナレッジ（fish-knowledge）

魚種記事・施設記事・タックル記事を書くときに、**最初に読む一次ナレッジ置き場**。
運用ルール（いつ・どの順で読むか）は `.claude/skills/kaijo-fish-knowledge/SKILL.md` が正本。ここは「何を・どう書くか」の規約。

## 出所タグ（全ての記述に付ける）

| タグ | 意味 | 信頼度 |
| :--- | :--- | :--- |
| 【一次】 | サイト運営者（さしし）本人が提供した経験・知見・見解 | 最高。他と矛盾したらこちらが勝つ |
| 【DS】 | `.data-set/` の【DS】ファイルなど、根拠つきデータ | 高 |
| 【記事】 | 公開済み記事から転記。**AI執筆の可能性があり、未検証** | 中〜低 |
| 【要検証】 | 出典のない数値・断定、記事間の矛盾、体験談風の記述 | 記事に新規で書かない |

- 【一次】は**本人の発言に基づく内容にだけ**付ける。AIが推測・補完して付けてはならない。
- 空欄（`（未記入）`）は空欄のまま残す。埋めたい場合は本人に聞くか、【要検証】として別枠に書く。

## 優先順位（矛盾したとき）

`【一次】 > 【DS】 > 【記事】 > 外部検索（WebSearch/WebFetch）`

外部検索で得た情報は、ここに追記するときに出典URLと取得日を付けて【要検証】から始める。

## ファイル構成

```
.data-set/fish-knowledge/
├── README.md        # 本ファイル（規約・進捗表）
├── _template.md     # 新しい魚種を追加するときのひな型
└── {slug}.md        # 魚種ごとのナレッジ。slug は fish-strategy のディレクトリ名と揃える
```

地域別の施設・料金・ブランド魚は `.data-set/【DS】海上釣り堀_地域別釣法・ブランド魚データベース.md` と施設記事の frontmatter（`target_fish`）が正。魚種ファイルには「その魚種に関する地域差」だけを書き、施設一覧は複製しない。

## 既存記事に共通する要検証パターン（全魚種）

14魚種の下書きで繰り返し見つかったもの。魚種ごとの詳細は各ファイルの「10. 要検証リスト」。

- **冒頭の体験談**: 多くの派生記事（intermediate / advanced / strategy / theory / gourmet）が「正直に言うと〜しました」「〜したことがあります」型の一人称エピソードで始まる（ブリ・カンパチ・ヒラマサ・シマアジ・イシダイ・チヌ・メジナ・イサキ・スズキ・カワハギ・アジ・フグ・マダイ）。運営者の実体験か不明。【一次】で確認できたものだけ残す。
- **出典のない数値**: 「短期記憶が○分」（マダイ15〜30分、ブリ30〜60分、シマアジ20〜30分、チヌ3〜5回で学習）、吸い込み時間（シマアジ・スズキ・カワハギで値が食い違う）、噛む力、速度、栄養数値、成功率の％。測定値として書かない。
- **号数・サイズの不一致**: ハリス・針の号数が同一魚種の記事間で大きく食い違う（スズキ・イシダイ・クエ・ヒラマサ・フグ等）。想定する魚のサイズや狙い（耐える／自然に見せる）を明記するか、運営者の実感で統一。
- **ドラグ・竿の扱いの矛盾**: 「完全ロック厳禁」（青物）と「フルロック」（クエ）、竿を立てる（青物）と寝かせる（スズキ・シマアジ）など、魚種・局面ごとの違いが明記されていない。
- **まとめ箇条書きの水増し**: 「3つのポイント」と言いながら4〜11項目並ぶ。リライト時に整理。
- **gourmet 末尾のシリーズ送りリンク**: shimaji → isaki → mejina → aji-asaba-kamasu、kue / suzuki / kawahagi / aji の gourmet も別魚種へ誘導する。意図した導線か確認。
- **ディレクトリ名とタイトルの食い違い**: hiramasa の intermediate は【戦略】、strategy は【中級】。
- **gourmet が無い魚種**: buri / kanpachi / hiramasa / ishidai は strategy ページを持ち、gourmet は無い（食味・熟成の記事が未整備）。
- **ルール依存の記述**: コマセ可否（メジナ記事は「許可されている」、チヌ記事は「多くの施設で禁止」、イサキ記事は「施設により異なる」）、ルアー可否、複数針可否は施設ごとに異なる。断定しない。
- **フグの安全記述**: 毒・資格・法規に関わる断定は書き足さない（`fugu.md` 冒頭を参照）。
