## 3. 釣り方

### 3.1 釣法の使い分け

- ウキ釣り: 朝一の高活性時、イケス中央の広範囲を探る基本 — 【DS】必勝釣法・テクニック体系化データ
- ミャク釣り（サグリ）: 日中の食い渋り、居食い攻略、ネット際。タナ変更が瞬時にできる — 【DS】同上
- ズボ釣り: 冬の低活性時、底に張り付いたマダイ・根魚 — 【DS】同上

### 3.2 タナ合わせ・アタリ・合わせ — 【記事】

- 底ギリギリにウキ下をセット → 30cm単位で浅くし、アタリが出たタナを集中的に狙う
- 2段階捕食: ついばみ → 確認 → 本飲み。ウキが完全に消し込んでから斜め後方へ鋭くひと振り
- 15分アタリがなければ10〜20cm動かす。隣の釣れている人のウキ下を真似るのが最速

### 3.3 誘い — 【記事】

- 聞き合わせ（5〜10cm持ち上げて止める）、落とし込み（テンションフォール）、打ち返し自体も誘い
- アタリは「止めた瞬間」に集中する。止める時間は3〜10秒が目安
- 動かす速さは1秒で5〜10cm程度のスローな動き（急な動きで逃げる）
- 速度の根拠: 摂餌行動を最も誘発するのは秒速2.5cm（水槽実験） — 【DS】科学的エビデンス・理論データ

### 3.4 食い渋り・スレ対策 — 【記事】

- エサのローテーション: 黄ダンゴ → シラサエビ → 赤ダンゴ/殻付きエビ → ササミ黄色染め。30分目安
- ハリスを細くする（2号 → 1.5号）。ドラグも同時に緩める
- 居食い対策: 0.8〜1.2号の極細ハリス＋軽量針、ゼロテンションでラインの「ピン」「ふわり」を見る、2〜3cmの聞き合わせ → 重みを確認して合わせる
- 網際・コーナー攻略: プレッシャーが高い時間帯は大型が網の四隅・壁際に寄るとされる（記事の主張）
- 変化球エサ: ミニトマト半切り、スイートコーン、生ホタルイカ

## 4. 季節・水温・時間帯

- 低水温で代謝が落ち「食べる絶対量が減る」。消化吸収効率自体は大きく変わらない — 【DS】科学的エビデンス・理論データ
- 低水温期は嗅覚・味覚刺激が鍵。夕方に摂餌量が増える傾向（養殖給餌の知見） — 【DS】同上
- 冬: 動かさない置き釣り、底を5〜10cm刻みで精密にタナ調整 — 【記事】
- 盛夏: 早朝に活性が集中、日中は底深く — 【記事】
- 天候: 曇りは浮きやすい、快晴は底に落ちる、雨で警戒心が下がることがある — 【記事】

## 6. エサ・仕掛け・タックル

- 色: 黄・オレンジ・赤に強く反応し、青を忌避する傾向。4種の錐体細胞を持ち紫外線も感知 — 【DS】科学的エビデンス・理論データ
- 水深5mで赤は黒く、10mでは青以外は明暗でしか区別できない。赤は深場で黒いシルエットとして効く — 【DS】同上
- 嗅覚（アラニン）と味覚（プロリン）を1:2で配合すると摂餌行動が最も活発になる — 【DS】同上
- 青物と兼用する場合、マダイ用の軟らかい竿は青物に伸され、青物用はマダイのアタリを弾く — 【DS】タックル・ギア需給ギャップ分析
- 軽量針は「エサの自然な漂い」を作る（グレ針3〜4号、海津4〜5号、袖5〜6号） — 【記事】
- 物販カードの設計は `.workspace/affiliate-tags/物販/` を参照

## 7. アタリ・失敗パターン・FAQ — 【記事】

- アタリはあるのに掛からない → 早合わせ。完全に消し込むまで待つ。針を小さくする
- エサだけ取られる → エサが大きすぎる可能性。小さく切る。エサ取りが多い場合は硬いエサへ（【DS】ユーザー悩み・解決策データベース）
- 途中でバレる → ハリスが細すぎる、またはドラグが強すぎて口切れ。ドラグを緩めて竿の粘りで受ける
- 隣は釣れて自分だけ釣れない → タナのズレが最大要因

## 8. 食味・持ち帰り

- 熟成14日目がうま味のピーク。遊離グルタミン酸が14日間で約3倍 — 【DS】魚の持ち帰り・熟成・調理データ
- 血が残ると脂質酸化で6日目から臭気 → 血抜き必須 — 【DS】同上
- 人工飼料のみで育った養殖魚はアニサキスの侵入経路が無く寄生リスクは事実上ゼロ — 【DS】科学的エビデンス・理論データ
- 処理手順: 脳締め（30秒以内）→ 血抜き（5分）→ 神経締め（任意）。津本式、熟成刺身・炙り・塩焼き・鯛めしの展開 — 【記事】gourmet
