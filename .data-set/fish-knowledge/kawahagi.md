## 3. 釣り方

### 3.1 基本 — 【記事】index

- エサは小さく、1口で飲み込める大きさ。「小さすぎる？」くらいがちょうどいい
- アタリは「コトコト」「クンクン」。穂先の0.5cm程度の揺れ、ウキの小さなピクつき、ラインの横の動き。感度の高い竿と細ハリスが必須条件
- タタキ誘い: 竿先を小刻みに上下（1〜2秒に1回）、10〜15回行い一瞬止める。止めた瞬間にアタリが集中
- 合わせ: 初心者は即合わせから。送り込み合わせの選択肢もあり
- 潮が動く時間帯に活性が上がる。潮止まりはタタキで引き出す

### 3.2 ゼロテンション（中級） — 【記事】intermediate

- ラインの張りを感じると吐き出す。オモリを底に着け、竿先を5〜10cm送り込み、水面でS字のたるみを作る。アタリは穂先の「クンッ」かラインが「スッ」と走る動き
- 宙釣り（放流直後・活性高）: 底から20〜50cm。ハワセ（活性低・スレ）: 底に寝かせる、底から5〜15cm
- タタキ（毎秒3〜5回・幅3〜5cm）→ 静止3〜5秒 → 聞き合わせ（5〜10cm）。能動的アタリ（コクン）は即合わせ、受動的アタリ（聞いて重み）はスイープ合わせ
- エサ消耗が激しい。半日で50〜80個分（アサリむき身2〜3パック）
- 仕掛け例: 竿2.4〜3.0m軟調グラス、2000番、フロロ1.5号直結、カワハギ専用3号の3本針、オモリ8〜12号
- 釣り座: 底網の継ぎ目・縁、コーナー、桟橋下が有利。偏光グラスで影を探す

### 3.3 高感度メタルトップ（上級） — 【記事】advanced

- 咀嚼のカリカリ（高周波）を感じる。カリカリが止まった瞬間が合わせのベスト。手首のスナップで短く鋭く
- 竿を握りすぎない（親指と人差し指の2点支持）
- 30秒サイクル: タタキ10秒 → 静止5秒 → テンション・フィード1秒 → 聞き合わせ
- 冬はタタキをゆっくり、静止を60秒に延長、エサを小さく
- 針を完全に隠さない（針先5mm程度出す）。ハリス0.8〜1.0号×10〜20cm、エダス0.6〜0.8号×5〜8cm、オモリ10〜15号
- 胴突き2〜3本針で複数の深さを同時に狙う案

### 3.4 吸い込みの理屈（理屈） — 【記事】theory

- 「吹き（ウォータージェット）→ 吸い」の波状。咽頭歯でさらに粉砕。エサのベロ部分だけを針に刺すと吸引されやすい
- 着底直後の「吹き吸い」に対応して、着底と同時に竿先でわずかにテンション
- 小型（15cm以下）は針とエサをさらに小さく
- カワハギのアタリ（短い高周波 → 一瞬の静止）で他魚と区別

## 4. 季節・水温・時間帯

- 秋（9〜12月）: 肝が膨らむ。食いも活発 — 【記事】index
- 冬（1〜3月）: 肝がやや落ちる（index）。gourmet では冬（12〜2月）が肝最大（寒カワハギ）— 【記事】（食い違い）
- 春〜夏: 産卵後で体が薄く肝も小さい（index）、夏は肝が小さい（gourmet） — 【記事】
- 夏（25℃以上）: 朝のみ活発、早朝6〜9時に1時間で5〜10枚 — 【記事】advanced
- 冬は底に張り付き、完全ハワセ（5〜10分静置 → 1cm聞き上げ）。11〜14時の水温が上がる時間に集中 — 【記事】

## 7. アタリ・失敗パターン・FAQ — 【記事】

- エサだけ取られる → エサが大きい。小さく、タタキで動かす、塩締めで硬く
- アタリを感じて合わせてもスカる → 合わせが遅い、針が大きい、針が鈍い
- ゼロテンションにしてアタリが分からない → たるませすぎ。聞き合わせを頻繁に
- カワハギ以外の外道（マダイ・フグ）が取る → 殻付きエサ・カニに切り替え（記事の主張）
- バラシが多い → 針が皮1枚に掛かっている。聞いた後は一定速度で巻く

## 8. 食味・持ち帰り

- カワハギ個別の熟成データは【DS】に無い。【記事】gourmet の内容:
  - 肝（苦玉＝胆嚢を潰さない。腹は浅く割き、苦玉と肝の間の管を引き離す）、薄い塩水で血抜き5〜10分
  - 肝醤油の目安: 肝大さじ1、濃口醤油大さじ1、みりん（煮切り）小さじ1.5、レモン数滴。肝和えは食べる30分前
  - 肝は冷蔵で2時間以内（またはその日のうちに）、冷凍は最大4週間
  - 唐揚げ（骨まで）、肝入りみそ汁
  - 肝が最大なのは冬（11〜2月、寒カワハギ）という記述
- 人工飼料のみで育った養殖魚はアニサキスの侵入経路が無く寄生リスクは事実上ゼロ — 【DS】科学的エビデンス・理論データ
