## 3. 釣り方

### 3.1 基本（泳がせ） — 【記事】

- 回遊魚で、イケス内を一定コースで周回する。動くエサを追うリアクションバイトが主。動きがアピールの核心
- 活きアジは背びれ前方・側線の少し上に背掛け（内臓を避けて長持ち）。鼻掛けは動きが落ちるが外れにくい
- アタった方向・コースを覚えて同じ場所・角度に入れ直す
- 誘い: 竿を大きく1〜2回シャクる（活き餌がパニックになる）、速い打ち返し。シャクりすぎると餌が弱る
- 地域のやり方: 三重では活きアジの泳がせが主流（【DS】地域別釣法・ブランド魚データベース）

### 3.2 死にエサ（中級） — 【記事】

- 活き餌は「動き」、死にエサは「匂いと脂」でアピール。放流後2〜3時間のスレた時間帯が出番
- サンマ（3〜5cmぶつ切り、片面の皮を剥く）、イワシ（1匹掛け、内臓に軽く傷）、カツオ切り身（最終手段）。縫い刺しで回転を防ぐ
- ジャーキング: 20〜30cm鋭く跳ね上げ → 1〜2秒緩める → 3〜5回繰り返して5〜10秒静止。バイトは止めた瞬間に集中
- 時間配分の例: 静置2分 → ジャーキング → 静置 → ジャーキング。5分ごとにエサ交換
- 2本竿の役割分担: 1本は活きアジ（寄せ）、もう1本は死にエサ静置（足止め）。竿本数制限は施設で要確認
- 前日にカットして冷蔵したサンマは匂いが強くなる（3日以上は腐敗臭）

### 3.3 放流直後の戦略 — 【記事】strategy

- 放流3分前までに、活きアジ・予備仕掛け・タモ・隣への声かけを済ませる
- 「攻めのドラグ」: 通常より硬めにして1〜2分で取り込む（ハリス4〜5号以上が前提）。冬は通常寄り
- 1匹取ったら血抜き・神経締めは後回しで即再投入（目標1分以内）
- 時間帯別: 0〜15分は攻め、15〜30分は通常に戻す、30〜60分は死にエサ・リアクション、60分以降はタナを広く
- 放流時刻は施設ごとに決まったパターンがあるので受付で確認

### 3.4 ファイト・ランディング — 【記事】advanced

- 竿は45〜60度。立てすぎ・寝かせすぎはNG
- 網際に近づいたときだけ指でスプールを押さえる（サミング）
- コーナーに向いた瞬間にバットでリフトアップ。入られたら竿先を水中へ、テンション一定
- タモ入れは魚が横を向いて浮いてから、下から掬う。タモは広げて手元に置く
- 網際を通った後や傷が疑わしい場合はリーダー交換
- 掛けたら声を出す（オマツリ防止）。10kg超は施設スタッフの補助も検討

### 3.5 捕食スイッチ・連鎖 — 【記事】theory

- 側線で低周波振動を感知。活き餌のパニックや仲間のヒットが刺激になり、フィーディング・フレンジー（連鎖）が起きる
- 誰かがヒットしたら即投入。長時間アタリがなければ大きなシャクりで振動を作る
- 水流の上流側にエサを入れる（向流行動）

## 4. 季節・水温・時間帯

- 秋（9〜11月）: 活き餌への反応が最良、連鎖が最も起きやすい — 【記事】
- 冬（12〜2月）: 脂ピーク。活性は低め、連鎖は小規模で個体狙い。静置・熟成サンマ・一口サイズ — 【記事】
- 盛夏: 早朝に集中 — 【記事】
- 天候: 曇りは浮きやすい、快晴・凪は鈍い、風雨は警戒が下がる傾向 — 【記事】
- 低水温期は嗅覚・味覚刺激が鍵（養殖給餌の知見） — 【DS】科学的エビデンス・理論データ

## 6. エサ・仕掛け・タックル

- 活き餌のバケツは水量と水温管理が重要。エアレーション、真夏は氷。投入は水面にそっと置く — 【記事】
- 死にエサは前日購入・当日朝カット・氷水保存。カツオは冷凍可 — 【記事】
- 青物と兼用する万能竿の目安: 3.0〜3.3m、Mクラス、6:4〜7:3。青物専用竿の別設計は物販タグ側（`.workspace/affiliate-tags/物販/`）を参照 — 【DS】タックル・ギア需給ギャップ分析

## 7. アタリ・失敗パターン・FAQ — 【記事】

- 放流されているのにアタリがない → 回遊コースからずれている、または活き餌が弱っている
- 途中でバレる → ハリス・針が小さい、竿を下げてエラ洗いを誘発
- ハリス切れ → ドラグ締めすぎ。逆に緩めすぎるとオマツリ
- バイトがあっても乗らない → フォール中のアタリをテンションを抜いて逃している
- 活き餌がすぐ弱る → 水量・水温・エアレーション
