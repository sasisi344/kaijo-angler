## 3. 釣り方

### 3.1 基本 — 【記事】

- 活き餌は大きめが有効。小さいと見向きされないことがある
- ウキ下は底付近から。15〜20分反応がなければ50cm刻みで上げる
- 「追いかけさせて確信させる」演出が鍵。好戦的だが、違和感があれば即Uターンする
- 放流直後が最もアグレッシブ。時間が経つと警戒心を取り戻す

### 3.2 誘い（中級：動の誘い） — 【記事】intermediate

- 動くもの・逃げるものへの執着が強い。漂うだけの活き餌は見切られやすい
- ロッドシェイク: 5〜8cm幅、毎秒3〜4回、10〜15秒 → ピタッと3〜5秒停止。停止直後にアタリが出やすい
- フリーフォール: 竿を一気に下げテンションゼロで2〜3秒 → 立ててテンションを戻した瞬間に合わせる
- 活き餌の元気度管理: ウキの動きで確認（動かない＝弱り）。エアレーション、夏は氷、海水使用
- 網際追い込み: 網から30〜50cm離して追い込む動きを演出。掛けたら中央へ誘導

### 3.3 サイトフィッシング（上級） — 【記事】advanced

- 浮いている魚の進行方向3〜5m先に静かに着水。真上に落とさない。サイドキャスト、着水音を消す
- 焦らし → 魚が後退し始めた瞬間に素早く4〜5回転巻いて逃がすフリ（ピックアップ）
- 2人で隣り合ってエサを並べ、一方を引き上げて競争心を煽る
- スプックしたら5〜10分待ち、底で仕切り直す
- 偏光グラスが前提

### 3.4 二段構えのタナ設定（戦略） — 【記事】strategy

- 底だけに置き続けると馴化して反応しなくなる
- 中層で動きのアピール（3〜5分）→ 急速フォール → 底付近で食わせ（静止30秒〜1分、聞き合わせ）→ 再び中層。約5分周期
- 中層は動き（活きアジ・ウグイ）、底は匂い（弱った活きアジ・死にイワシ・サンマ）で役割分担
- 2人で連携し、片方が中層、片方が底で待機

### 3.5 ファイト — 【記事】

- 掛けたら即座に竿を立てて底への突っ込みを止める（最優先）。竿の弾力で受け、ドラグに頼りすぎない
- 横走りは走る方向と逆に竿を保つ。浮いてきた隙を逃さず寄せる
- 5〜10分底から浮かないことがある。一定テンションで根気よく
- ハリス切れの原因は結び目の甘さも多い。出発前に結び直す

## 4. 季節・水温・時間帯

- 夏（7〜9月）: 活性最高。盛夏は朝一に集中 — 【記事】

## 7. アタリ・失敗パターン・FAQ — 【記事】

- アタリはあるが乗らない → 活き餌が弱っている
- ヒット直後にハリス切れ → ハリスが細い、結び目の強度不足
- フックアウト → 針が小さい、またはドラグが緩すぎる
- 近づいてこない → シェイクが遅い、止めが短い（5秒以上）
- 網際でハリス切れ → 網に近づけすぎ。掛けたら素早く中央へ
