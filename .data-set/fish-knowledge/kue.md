## 3. 釣り方

### 3.1 基本 — 【記事】index

- 待ち伏せ型。底の四隅・網際でじっとして動かない。「クエのいる場所にエサを届ける」ことが前提
- ウキ下は水深より少し深めにして底に置く。軽い弛みを持たせる。誘うなら10〜20cm持ち上げてゆっくり下ろす
- エサは通常の倍以上の大きさ・匂い強め。置き竿でも30分ごとに交換
- 側線が鋭く、大きな音・不自然な振動で警戒する。足音・大声・着水音に注意
- 一撃のチャンス。竿を手に持って待機するのが理想
- 合わせ: ウキが沈んでから3〜5秒待つ（index FAQ）

### 3.2 匂いの戦略（中級） — 【記事】intermediate

- 嗅覚重視。カツオの血合い（瞬発的に広がる、2〜3cm角、押しつぶしてエキスを出す）とサンマぶつ切り（持続的、40〜60分）、サンマ内臓入り（最強）
- 水流を見て潮下の角・網のたるみが匂いの吹き溜まり。投入点は潮上1〜2m、静水なら四隅を直接
- 重ね投入: 撒きエサ（針なしの血合い2〜3片）→ 本命（サンマ針付き）→ 30分静置。撒きすぎは濃度勾配が崩れる
- 低水温は前日に切って一晩寝かせた熟成エサ、高水温は切り立ての新鮮なカツオ
- 縫い刺しは2〜3か所通す。冷凍サンマは半解凍で使う

### 3.3 ピンポイント攻略（上級） — 【記事】advanced

- サウンディング: 四隅から順に落として着底感触を確認。「コツ」と止まる場所に居着く可能性
- 真上から垂直に降ろす（投げると網に当たる）。着底後5〜10cm浮かせる（ボトムバンプ）。ゼロテンションでたるみの中をふわふわ漂わせる
- アタリ: ザラザラ（網に触れている）、スーッ（自由）、コツッ（口で押さえた）、ズーン（走り出した）
- 合わせ直後にドラグをフルロックし、バットで最初の0.5〜3秒に一気に網から引きずり出す
- 潜られたらテンションをゼロにして10〜30分待機。竿先を水中に入れて角度を変える
- 毎投後にハリス先端10cmを爪で確認
- 大型（5kg超）は施設スタッフ・同行者のタモ補助が前提

### 3.3b 音の使い分け（理屈） — 【記事】theory

- 警戒音（ドスン・ずり引き）は最大1時間口を閉ざす。ゆっくり垂直に着底させる（サミングで減速）
- 誘惑音（タッピング）: 完全静止3〜5分 → 竿先3〜5cmで「トッ」と一度 → 数分待つ → 10分後に繰り返し。連打は逆効果
- 弱い最初の引きに慌てて合わせない（ドラグがじわっと出るまで待つ）

## 4. 季節・水温・時間帯

- 秋（9〜11月）: 行動範囲が広がる。冬（12〜2月）: 底でじっと。匂いの強いエサ — 【記事】index
- 20〜23℃の春（4〜6月）と秋に最も活性が高い、冬は低活性だが大型が出やすい、夏は早朝のみ — 【記事】intermediate FAQ
- 盛夏は底の酸素量が低下し、底から50〜70cm上も探る案（advanced）
- 冬は静置時間を長く、垂直投入を正確に — 【記事】advanced

## 7. アタリ・失敗パターン・FAQ — 【記事】

- 放流されているのにアタリがない → 1日アタリがない日もある。四隅・底網際に届いているか確認
- ハリス切れ → ハリスが細い。掛けた瞬間に竿を上げる（下げると底に張り付く）
- 乗らない → エサが大きすぎる、合わせが早い
- 小型魚にエサを取られる → エサを大きく（5cm角以上）、オモリを重くして沈下速度を上げる
- 取り込み後は濡れタオルで目を覆うと落ち着く。エラカバーが鋭いので素手で持たない

## 8. 食味・持ち帰り

- クエ個別の熟成データは【DS】に無い。【記事】gourmet の内容:
  - 処理: 脳天締め（30秒以内）→ 血抜き → 神経締め → 氷水で冷却 → 内臓除去
  - 皮が分厚く鱗が硬いため「すき引き」で皮を傷つけない。霜降りは熱湯10〜15秒 → 氷水
  - クエ鍋（クエちり）: 骨をローストし弱火70〜80℃で60〜90分、昆布は最後15分。切り身は沸騰スープで3〜4分
  - 刺身の昆布締め1〜2時間、アラは鍋・潮汁、カマは塩焼き・から揚げ
  - 旬は冬（11〜2月）だが養殖は通年安定
  - 栄養: コラーゲン豊富（Ⅰ型）。数値は要検証
