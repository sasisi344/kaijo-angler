## 共通の問題点

### 1. ボリューム不足
- 全記事が 50〜75行と極めて短い
- 本文コンテンツは実質 20〜30行程度
- 検索エンジン・読者視点から見て「薄い」印象

### 2. テンプレートの画一化
全記事が同じ構造：「はじめに → セクション1〜3（箇条書き） → まとめ → 詳細記事リンク」に固定されており、魚種ごとの個性が出ていない。

### 3. HTMLタグの混入
これに関しては、markdownのboldルールだとエラーが出やすいため、strongタグで固定するように指示している。もしmarkdwonのboldを使うルールが残っているなら改善してほしい。
本文中に `<strong>` タグが多用されている。ワークスペースルール（CLAUDE.md）では Markdown の `**太字**` を使うことが定められており、修正が必要。

### 4. 欠落しているコンテンツ要素
- 季節・時期別の攻略ポイントがない
- 具体的な数値（推奨タックルスペック）がない
- FAQ（よくある質問）セクションがない
- 初心者〜上級者への段階的な案内がない
- 釣果の目安・難易度の具体的説明がない
- 天候・潮回りの影響が触れられていない
- 施設記事へのリンク（横断誘導）がない

### 5. SEO的な弱さ
- 導入文が短く、検索意図（「釣れない理由」「釣り方を知りたい」）を拾えていない
- 見出し構成が浅く、H3レベルの情報整理がほぼない

## リライト後のターゲット構成（共通テンプレート）

各記事を **150〜200行（実コンテンツ換算で 1,200〜2,000字）** を目安に拡充する。

```
# [魚種名]を海上釣り堀で釣る：[キャッチコピー]

## [魚種名]とは（概要・魅力の紹介）
- 生態の簡単な説明（イケス内での動き）
- 難易度評価（★☆☆〜★★★ + 一言コメント）
- 釣れたときの価値（食味・希少性）

## 基本情報まとめ（テーブル）
| 項目 | 内容 |
|------|------|
| 推奨タナ | 〇〇m〜〇〇m |
| 活性の高い時間帯 | 朝マズメ・放流直後 等 |
| おすすめシーズン | 春〜夏 / 通年 等 |
| 推奨エサ（定番） | 〇〇、△△ |
| 推奨エサ（食い渋り時） | 〇〇、△△ |
| ハリスの目安 | 〇号（フロロカーボン） |
| 針の目安 | 〇号〜〇号 |

## 生態と釣り堀での動きを理解する
- イケス内での回遊パターン
- 捕食スイッチが入る条件
- 釣り人への警戒・スレへの対策ポイント

## 攻略の基本（初心者向け）
- タナ合わせの手順
- 基本エサの選び方・つけ方
- アタリの取り方・合わせ方

## 中上級者向けの応用テクニック
- 食い渋り時の対応
- 誘いのパターン（具体的な動作説明）
- 周囲との差をつけるポイント

## 季節・状況別の攻略ポイント
- 水温が高い時期 vs 低い時期
- 放流直後 vs 時間が経過した後
- 天候・潮の影響

## よくある失敗と対策（FAQ）
- Q: アタリはあるのに釣れない
- Q: エサだけ取られる
- Q: 途中でバレてしまう

## 関連する詳細記事（内部リンク）
→ 既存の intermediate/advanced/theory/gourmet リンク
```

## 技術的な修正事項（全記事共通）

1. **`<strong>` → `**太字**` への置換**
   - 日本語ではmarkdownのboldルールは抜けが発生しやすく自由度がないので、記事で使う場合はstrongタグで固定する。AIが出力する行動指示ファイルやタスク管理はmarkdownでいい。

2. **frontmatter の整理**
   - `created:` フィールドは Astro のスキーマ定義にないため削除
   - `lastmod:` も不要（スキーマに `updateDate` が正しい）
   - `slug:` フィールドは新 Astro Content Layer では不要

3. **詳細記事リンクの英名修正**
   - `kanpachi攻略` → `カンパチ攻略` 等、日本語に統一

---

## 参考：既存の詳細記事（手本として活用）

詳細記事（`intermediate/`, `advanced/` 等）は既に充実した内容となっている。
index.mdx の拡充にあたり、詳細記事のネタを一部要約して引用し、「さらに詳しくはこちら」と誘導する構成が効果的。

例：`madai/intermediate/index.mdx` の「エサローテーション戦略」「色別のローテーション」は madai index の拡充に流用できる。
