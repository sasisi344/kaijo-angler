# メディア平均Research（第3弾）— 台帳の候補を埋めるための集計

作成: 2026-09-30／ステータス: **途中（マダイ・シマアジ・ブリ/カンパチのみ。他魚種は未実施）**

## 方法

- クエリ: 「海上釣り堀 おすすめ {魚種} {タックル種別}」（竿・リール・仕掛け・ハリス・針・エサ）を実行し、上位に出たページから海上釣り堀向けタックルの商品名・価格・仕様を抽出。**商品ごとに「何のメディアで推奨されたか（出現数）」と「価格の平均」**を集計し、台帳の候補名称に当てはめる
- **制約（要注意）**
  1. 使った検索ツールはGoogle日本の実SERPではない。上位結果は実際の順位とずれる可能性がある。またtsurihack・tacklenote・my-bestの特定記事が全クエリで繰り返し上位に出るため、「上位5サイト」は実質的に**十数ページの同じ集合**になる
  2. 取得したのは各ページの要約（WebFetch）。出現数は**確認できたページ内の掲載数**で、網羅的な統計ではない
  3. 途中で検索のレート制限（too_many_requests）に達し、ブリ×エサは未検索。ちがう魚種（チヌ・スズキ・イシダイ・イシガキダイ・クエ・ハタ）は未実施（底物竿は確定済みのため竿は対象外）
  4. 価格は各記事の記載値（税込/実売の混在）。掲載前にAmazonで再確認する
- 情報源ページ: tsurihack（[竿15選](https://tsurihack.com/6298)・[リール10選](https://tsurihack.com/8554)・[タックル&仕掛け](https://tsurihack.com/6275)・[おすすめタックル](https://tsurihack.com/2421)・[エサ](https://tsurihack.com/6310)）／[my-best 竿ランキング](https://my-best.com/15123)／tacklenote（[竿16選](https://corp.tacklenote.jp/columns/marine-fishing-rod/)・[青物ロッド8選](https://corp.tacklenote.jp/columns/marine-fishing-pond-blue-fish-rod/)・[リール16選](https://corp.tacklenote.jp/columns/sea-fishing-pond-reel/)・[スピニングリール8選](https://corp.tacklenote.jp/columns/marine-fishing-pond-spinning-reel/)・[仕掛けセット8選](https://corp.tacklenote.jp/columns/sea-fishing-pond-tackle-set/)・[ハリス8選](https://corp.tacklenote.jp/columns/maritime-fishing-pond-harris/)・[針10選](https://corp.tacklenote.jp/columns/marine-fishing-pond-hook/)）／[fishingjapan ロッド](https://fishingjapan.jp/fishing/7031)・[エサ](https://fishingjapan.jp/fishing/10374)／[tfishing 脈釣りロッド](https://tfishing.net/tsuriborimyaku-rod/)／tsurinews（[シマアジ](https://tsurinews.jp/108746/)・[青物](https://tsurinews.jp/291818/)）／[tsurisoku マルキユー練りエサ](https://www.tsurisoku.com/news/71484/)／[釣堀紀州](https://www.tsuribori-kishu.com/kaijyou-tsuribori-takkuru/)
