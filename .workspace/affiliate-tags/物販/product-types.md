# 商品タイプと必須項目

| typeコード | 内容 | 補足 |
|---|---|---|
| `rod` | 竿 | 竿カテゴリA/B/Cと価格帯を記載 |
| `reel` | リール | 番手（2500〜5000）と価格帯 |
| `line` | 道糸 | PE/ナイロン/フロロ・号数 |
| `harris` | ハリス | 素材・号数・長さ |
| `rig` | 市販仕掛け・セット | 針号数・ハリス号数・ウキの有無 |
| `hook` | 針 | 号数・形状（伊勢尼・チヌ・ロングシャンク等） |
| `float` | ウキ・オモリ | 棒ウキ号数・クッションオモリ |
| `bait` | エサ・コマセ | 練り餌・ペレット等 |
| `set` | 竿リール込みの入門セット | clunTEN等 |
| `gear` | 携行品（グリップ・プライヤー等） | 魚種共通なら`common` |

## 台帳の必須項目（fish/{fish}.md の各行）

`type` / 商品名 / ブランド / ASIN / リンク（標準形） / 価格（確認日付き） / 価格帯（entry・std・pro） / 用途（サイズ・号数） / 共用元 / ステータス（候補・確定・反映済み） / 備考（注意点）

## 価格帯の定義

| 帯 | 竿の目安 | リール（4000〜5000番）の目安 |
|---|---|---|
| entry | 〜1万円 | 〜1万円 |
| std | 1〜2万円 | 1〜2万円 |
| pro | 2万円〜 | 2万円〜 |
