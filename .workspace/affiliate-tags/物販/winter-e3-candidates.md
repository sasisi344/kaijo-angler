# E3 冬のカード8枚：Amazon 商品候補

> 2026-11-11 反映済み: 運営者が8カテゴリから1点ずつ選び、所感を書いた。所感の全文は `.data-set/first-timer-knowledge.md` §11【一次】。新規カード7枚＋登録済みのトランクマスター1枚を、`winter-kaijo-tsuribori-guide`（5枚、`placement="winter-guide"`）と P1 `winter-big-fish-nabe`（3枚、`placement="winter-nabe"`）に置いた

> [!important]
> `weekly-task.md` の E3（11/14）用の候補。**運営者（さしし）が「さししの所感」を1行書いたものから順に、Claude がカード（`src/content/affiliates/tackle/common-*.json`）にする。** 所感が空の商品はカードにしない。
> 所感はカードの `reason` の元にする。使ったことがなくても「なぜこれを選ぶか」「どんな人に向くか」でよい（使っていない物に使った感想は書かない）。
> 売り方は `kaijo-affiliate-sales` スキル、書き方の型は `hq/affiliate-copy-rewrite.md` §2。

## 使い方

1. 各カテゴリで採用する1点の「さししの所感」に1行書く。どれも違うと思えば、商品名だけ書いてくれれば Claude が探す
2. 採用しない行はそのまま（空欄）でよい
3. Claude がカード JSON を作り、ASIN をこの表に「登録済み」と書き、下の置き場所に `TackleCard`（`reason`・`placement`）を置く

## 書式

- 価格・評価・件数は **2026-11-11 時点の Amazon 検索結果**（スポンサー枠は除外）。カード化の直前に商品ページで確かめる
- 商品URL: `https://www.amazon.co.jp/dp/{ASIN}?tag=344kaijyo-22`
- 画像ID: `https://m.media-amazon.com/images/I/{画像ID}._AC_SL1500_.jpg`
- 「Claude のメモ」は検索結果から書いたもので、実物を使った感想ではない
