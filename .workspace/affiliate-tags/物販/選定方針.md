# 商品選定方針（タックル物販）

2026-09-30 追記。台帳（`fish/*.md`）の候補を確定するときの判断基準。根拠は[[media-average-research]]のメディア平均＋ユーザー方針。

## 1. 「海上釣り堀」名称入りの商品を優先してよい

- メディア平均では「海上釣堀」の名称が入った商品（竿・仕掛け・ハリス・針）が目立ち、価格帯も1〜3万円台（竿）・数百〜千円台（仕掛け）に収まっている。平均像として妥当なので、**海上釣り堀名称入り商品を第1候補にして問題ない**
- 「実際に売れるか」はメディア掲載とは別なので、`affiliate_id`×`fish`のクリック・成約データで後から検証する（[[../../.task/schedule-task]] M1）

## 2. 汎用性を重視する（海上釣り堀専用でなくても使える）

- 「海上釣り堀でしか使えない」商品より、**ネイティブ（通常の堤防・ショア等の釣り）でも使える商品**を重視する。購入者の再購入・用途拡大につながり、記事上でも「海上釣り堀以外でも使える」と訴求できる
- 例: ハードロッカー S83MH（ロックフィッシュロッド）、ショア/シーバス/ライトショアジギ系の短めルアーロッド、汎用スピニングリール4000番台、フロロ/ナイロンのハリス・道糸
- カード文言・記事内の紹介文に「海上釣り堀でも、〇〇（堤防/ショア等）でも使える」と入れる

## 3. 竿の長さは 2.5〜3.5m（8〜11ft）から選ぶ（改訂 2026-09-30）

- **範囲**: 2.5〜3.5m（8〜11ft）。**上限は3.5m（11ft）**。メディア上位の竿が3.5m以下に集中しており、施設の竿長さ制限に対応した長さと考えられる。長さ自体は11ftも要らないので、8〜11ftの範囲内から選ぶ
- **施設ごとの制限との突き合わせ**（施設別のタックル提示のための設計）:
  - 施設の竿長さ制限（`rod_length_limit`）が **3.5m以上、または未記載** → 標準候補（2.5〜3.5m）をそのまま表示
  - 制限が **3.5m未満**（例: 3m以下、3.3m以下） → 制限以下の竿だけを表示（短め帯の商品で対応）
  - 制限が **3.5mより上**（例: 4.5m） → 標準候補に加え、必要ならそれより長い竿も許容（区別して扱う）
- **⚠ 事前確認の結果（重要）**: 当サイトの施設記事に**竿の長さ制限は載っていない**。施設記事116件を調べたところ、竿に関する制限の記載は「竿の制限: 1人2本まで」（新舞子マリンパーク）と「竿数制限なし」（海上釣堀 和光）の2件のみで、いずれも本数であり長さではない。frontmatterの`facility_details`にも該当フィールドがない。メディア側の一般情報は「5m前後を禁止する施設が多い」「釣堀紀州は4.5m以上禁止」（**2026-10-06訂正**: 運営者の確認で、釣堀紀州に長さ制限の公式記述はなく、貸竿は3.2mの船竿・推奨仕掛けは3〜4m。この一般情報は採用しない）程度
  - → **施設ごとの竿長さ制限のデータ収集（公式サイト等）と、`facility_details.rod_length_limit`（数値m、任意）の追加が別途必要**（[[../../.task/subtask]]項目7）

## 4. リールは4000番台を基準にし、「4000番台を使う理由」をカード・記事に書く

メディア平均でも青物4000〜5000・マダイ3000〜4000、価格帯別の定番も4000番台が多い（ナスキー4000・ミラベル4000・ストラディック4000・ヴァンフォード4000）。記事・カードに書く理由の案（メディア記述に基づく）:

1. **糸巻量**: 道糸ナイロン6〜8号（PE3号）を100〜150m巻ける。青物・マダイの両方に使える標準的な糸巻量
2. **ドラグ性能**: メータークラスのブリ・カンパチには低速からスムーズに効くドラグが必要。4000〜5000番が使いやすい（tsurinews）
3. **兼用性**: 2500〜3000番（マダイ・シマアジ専用に軽い）と、5000番以上（大型青物向け）の中間。マダイ・シマアジ・青物・底物（ハタ・イシダイ）を1台でこなせる
4. **ネイティブでも使える**: 堤防・ショアのライトショアジギング、シーバス、ロックフィッシュ等にそのまま流用できる汎用番手
5. **価格帯が広い**: entry（セドナ・レブロス約6,400円）から pro（ヴァンフォード約2.5万円）まで4000番前後で揃う

- 注: 上記は記事の記述を要約した案。カード文言として公開する際は、番手ごとのメーカー公表スペック（糸巻量・ドラグ力）を確認してから数値を入れる
