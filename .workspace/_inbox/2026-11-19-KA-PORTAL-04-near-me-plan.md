# 要件定義: 施設一覧の「現在地から近い順」（KA-PORTAL-04 追加）

- 作成: 2026-11-19（CC、プランとして）／要件定義に書き直し: 2026-11-20（CC）
- 発端: 筆者の記入（`2026-11-19-decisions-KA-PORTAL-04-06.md` §6）「住んでいる地域からもっとも近いものを選ぶ機能性があればなおいい。スマホ向け」
- 筆者の決定（2026-11-19、プランへの記入）:
  - この形で実装してよい
  - 位置情報を使えない人には、地域のプルダウンに戻すだけ（出発地の県を選ばせる代替はしない）
- 状態: 要件確定。未実装

---

## 1. 目的

スマホで `/fishing-facility/` を開いた人が、地域を選ばずに **1回のタップで、近い施設から順に並べて見られる**ようにする。

- 地域・種類を選ぶ操作を減らす（筆者の方針「フォーム入力かクリックの回数は少ないほうがいい」）
- 「近いのはどこか」に答えて、施設記事と公式の予約へ進んでもらう

## 2. 対象と範囲

| 項目 | 内容 |
|---|---|
| 対象ページ | `/fishing-facility/` の「条件で探す」 |
| 主な利用者 | スマホで開いた人（PC でも使えるが、精度が低いので目立たせない） |
| 範囲に入る | 位置の取得、近い順の並べ替え、カードへの距離の表示、解除、使えないときの案内、計測 |
| 範囲に入らない | 地図（`MapApp`）の「現在地」ボタンとの共通化、所要時間（車・電車）の計算、出発地の県を選ぶ代替、位置の保存 |

## 3. 機能要件

### FR-1 ボタン

- 「条件で探す」の一番上に「📍 現在地から近い順」を置く
- スマホ幅（〜767px）では横幅いっぱい、PC では他の項目と同じ大きさ
- 近い順で表示している間は、ボタンの文言を「近い順で表示中（解除）」に変える

### FR-2 位置の取得

- ボタンを押したときだけ位置を取る（ページを開いただけでは許可を聞かない）
- `navigator.geolocation.getCurrentPosition` を使う。タイムアウト10秒、`maximumAge` 10分、`enableHighAccuracy: false`
- 取得中はボタンを押せなくし、「現在地を確認しています…」と表示する

### FR-3 近い順の並べ替え

- 位置が取れたら:
  1. 地域を「全国」に戻す
  2. 種類と行く日（休業の除外）で絞る。これは今の検索と同じ
  3. 現在地からの直線距離が近い順に並べる
- 希望の条件（竿・魚・はじめて向け）の「✓／×／？」の札は今どおり出す。ただし並びは距離を優先する
- 「もっと見る」（24件ずつ）は今どおり
- 座標のない施設は「距離不明」として末尾に回す

### FR-4 距離の表示

- 各カードに「直線で約 ◯km」を出す。10km 未満は小数1桁、10km 以上は整数
- 渡船のある施設（`needs_ferry: true`）には「渡船あり」を添える
- 一覧の上に「距離は直線です。車や船の所要時間とは違います」と一度だけ書く

### FR-5 解除と条件の変更

- 「近い順で表示中（解除）」を押すと、元の並び（北から・名前順、希望の条件が合う順）に戻し、距離の表示を消す
- 「条件をすべて解除」でも近い順を解除する
- 近い順の間に地域を選んだら、近い順を解除して地域で絞る（地域と近い順は同時に使わない）
- 近い順の間に種類・行く日・希望の条件を変えたら、近い順のまま絞り直す

### FR-6 位置を使えないとき

- 許可されない・タイムアウト・端末が対応していない、のいずれでも:
  - ボタンの下に「位置情報を使えませんでした。地域から選んでください」と出す
  - 地域のプルダウンにフォーカスを移す
- 並びと絞り込みは押す前のまま変えない
- もう一度押せば、再び位置を取りにいく

## 4. 非機能要件

| 区分 | 要件 |
|---|---|
| プライバシー | 緯度・経度をサーバー・GA4・URL・ブラウザーの保存領域のどこにも送らない・残さない。計算はブラウザーの中だけで行う |
| 計測 | GA4 に `facility_near_me` を送る。値は結果（`granted`／`denied`／`timeout`／`unsupported`）と表示件数だけ |
| 性能 | 103施設の距離計算と並べ替えは、押してから0.1秒以内（位置の取得時間を除く） |
| 依存 | 新しいライブラリを入れない。距離は2点間の直線距離（ハバーサイン式）を自前で計算する |
| 動作環境 | HTTPS（本番）と localhost（ローカル）で動く。位置情報のない環境ではボタンを出したまま FR-6 の案内にする |
| 表示 | 幅390pxで横にはみ出さない。ダークモードでも読める |
| 既存機能 | 位置を使わない人の検索（地域・種類・行く日・希望の条件・0件の案内・公式への導線）は今と同じに動く |

## 5. データ

- 施設の座標は `google_maps.latitude` / `google_maps.longitude`（施設記事の frontmatter に既にある）
- カード（`li.fs-card`）に `data-lat`・`data-lng`・`data-ferry` を足す
- 施設記事・スキーマ（`src/content/config.ts`）は変えない

## 6. 変更するファイル

| ファイル | 変更 |
|---|---|
| `src/pages/fishing-facility/index.astro` | ボタン、案内文、距離の表示場所、カードの `data-*` |
| `src/scripts/facility-search.ts` | 位置の取得、距離の計算、並べ替えへの組み込み、解除、計測 |

## 7. 受け入れ条件

Chrome の開発者ツール（Sensors）で位置を与えて確かめる。

| # | 条件 | 期待する結果 |
|---|---|---|
| 1 | 位置を大阪駅付近にして押す | 大阪・兵庫の海上釣り堀が先頭に並び、各カードに距離が出る |
| 2 | 位置を福岡市付近にして押す | 福岡・佐賀・長崎の施設が先頭に並ぶ |
| 3 | 位置を福井県美浜町付近、行く日を 2027-01-05 にして押す | 休業期間のひるが・ブルーパーク阿納は出ない。休業も表示にすると札付きで出る |
| 4 | 渡船のある施設（例: 水宝） | 「渡船あり」が添えられる |
| 5 | 近い順の間に種類を「海釣り施設」にする | 近い順のまま海釣り施設に絞られる |
| 6 | 近い順の間に地域を選ぶ | 近い順が解除され、その地域で絞られる |
| 7 | 「近い順で表示中（解除）」を押す | 元の並びに戻り、距離の表示が消える |
| 8 | 位置情報を「ブロック」にして押す | FR-6 の案内が出て、地域のプルダウンにフォーカスが移る。一覧は押す前のまま |
| 9 | Sensors で取得をタイムアウトさせる | 10秒で 8 と同じ案内が出る |
| 10 | GA4 のイベント（デバッグ表示） | `facility_near_me` に緯度・経度が含まれない |
| 11 | 幅390px | 横にはみ出さない。ボタンは横幅いっぱい |
| 12 | `node node_modules/astro/astro.js build` | 通る |
