# 物販候補リスト：ショア用ルアータックル／護岸向けチヌ仕掛け

> [!important]
> 南港魚つり園護岸のリライト（2026-10-16）で、記事の主役にしたい物販がアフィリエイトカードに未登録だと判明した。海釣り公園・護岸（タイプE 都市近郊）の施設記事で使う商品の候補をここに貯め、確定したら台帳 → JSON の順で登録する。
> 関連: [[travel-cta-sales-design]]／`.claude/skills/kaijo-affiliate-sales`（適用ログ）／`.workspace/affiliate-tags/物販/README.md`（登録手順・id命名）／[[選定方針]]

## 使い方

1. 候補を見つけたら下の表に1行追加する（ASIN・価格は分かる範囲で。空欄可）
2. Amazonで現行品・価格・ASINを確認したら「確認済み」にする
3. 確定したら `物販/fish/{fish}.md` に転記 → `src/content/affiliates/tackle/{fish}/{id}.json` を作成 → 「反映済み」
4. 記事には `<TackleCard id="..." placement="facility-gear" reason="（この釣り場で要る理由）" />` で入れる

ステータス: `候補`（名前だけ）→ `確認済み`（Amazonで現行品・ASIN確認）→ `確定`（台帳に転記）→ `反映済み`（JSON作成）

## 選ぶときの条件

| 条件 | 内容 | 根拠 |
|---|---|---|
| 竿の長さ | 2.5〜3.5m（8〜11ft）を基本にする | [[選定方針]] §3 |
| リール | 3000〜4000番。4000番を基準にし、理由をカードに書く | [[選定方針]] §4 |
| 汎用性 | 海釣り公園・堤防・海上釣り堀のどれでも使えるもの | [[選定方針]] §2 |
| 施設ルール | 南港は投げ釣り禁止・ルアー可・竿出し1人1本・活き餌の販売なし。ルール違反になる道具（投げ釣り用の遠投仕掛け等）は載せない | 南港記事 |
| 魚種 | 青物（ハマチ・メジロ。春と秋のルアー）、チヌ（足元・通年）。<strong>タチウオは対象外</strong>（下記） | 運営者の一次メモ（fish-knowledge buri / chinu） |
