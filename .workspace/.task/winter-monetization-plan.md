### タイトルの方針

事実と注意点は本文で書き、**タイトルは読者が行きたくなる場面**を描く。「対策」「攻略」「ガイド」だけで終わらせない。「最強」「完全攻略」「徹底解説」など規約の NG 表現は使わない。

| ID | タイトル案 |
|---|---|
| P1 | 冬の海上釣り堀は「大物を釣って鍋」が楽しい｜ブリしゃぶ・クエ鍋を釣るところから |
| W1 | 冬の釣りはなぜ釣れない？それでも大物に会いに行ける、海上釣り堀という選び方 |
| W2 | 冬に行きたい海上釣り堀◯選｜大物と温泉と海の幸がそろう、太平洋側の人気スポット |
| W3 | 冬の大物を鍋に連れて帰る3つの作戦｜エサ・タナ・時間帯 |
| W4 | 釣り納めの一匹で年を越す／正月の鯛は自分で釣る／初釣りで今年の運だめし |
| W5 | 冬のブリはどこにいる？脂ののった一本を釣って、鍋にするまで |

### 書いてはいけないこと

- <strong>「確実に釣れる」「絶対」は書かない</strong>。言えるのは「魚がいる」「天然より釣りやすい」まで。水温が下がると放流魚も食いが落ちる（ブリは13℃付近で摂餌が鈍る）ので、この注意は必ず添える
- 放流の日・量・魚種は、公式で確認できた施設だけ書く。確認できないものは「予約時に聞くこと」と書く
- <strong>旧記事はすべて全面リライトする</strong>。ペルソナ変更（2026-10-27）より前の文体で、料金も古い。使うのは論点だけで、本文は引き継がない。タイトルの「確実に釣る」も使わない
- 筆者が鍋を食べた体験は、筆者の記録があるものだけ書く。AI が一人称の体験を作らない

## 6. 外部の確認で見えたこと（2026-11-05）

- 冬の釣りの記事は「深場に移る」「ライトゲーム」「管理釣り場や船が無難」までが多く、**海上釣り堀に絞って冬の放流や釣れ具合を答える記事は、検索結果に見当たらなかった**。ブリを釣って鍋にする話も、冬に絞った記事は見当たらなかった
- ここが勝負どころになる可能性があるが、**確認に使った検索は日本の Google の結果ではない**。P1・W1・W2 の執筆前に、日本の検索結果で「海上釣り堀 冬」「冬 釣り堀」「冬 釣り堀 釣れない」の上位を確かめる
- 年末は放流を増やす施設や10kg級の大ブリを放流する施設がある、という紹介がある（つりHack。年代不明なので、そのまま書かず R3 の確認材料にする）
- 冬の定休日や年末年始の休みは施設で異なる（例: 広島の大漁丸）。W0・W4 は公式の確認が必須
