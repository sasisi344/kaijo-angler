# 11月末までのプラン：はじめての人の不安を埋める → その上で収益導線を作る

> [!important]
> 施設記事は「釣具を持っている経験者」を前提に作られていて、**「道具がないけど釣りできる？」「人生はじめてで大丈夫？」に答えていない**。施設紹介として致命的な欠陥なので、11月前半はこれを埋めることを最優先にする。収益導線は、その「はじめての人向け」の情報の上に乗せる（自分で用意するもの＝物販、遠方からの行き方＝旅行、という順に自然につながる）。
> 経験者は施設情報だけ知りたいので、**経験者の読み方を邪魔しない置き方**にする。
> **パラメータ・判定・本文の組み立ては [[first-timer-design]]**（2026-10-27）。
> 関連: [[travel-cta-sales-design]]／[[next-task]] 項目2（計測）／`.workspace/facility-data-update/`（施設データ更新）／スキル `kaijo-affiliate-sales`・`kaijo-fish-knowledge`

## 1. 現状：施設記事は経験者向けの構成になっている

施設記事116本（地域indexを除く）の調査（2026-10-27、本文の語句検索）:

| 確認したこと | 記事数 | 読み取れること |
|---|---|---|
| 見出し「メイン魚種の攻略」 | 99 | 標準の構成は「料金 → 魚種の攻略 → 周辺用品 → アクセス → FAQ」。**釣り方を知っている人向け** |
| 見出しに「初心者／はじめて／手ぶら」がある | **3** | はじめての人向けの節はほぼない |
| frontmatter `rental_tackle: true`（相当を含む） | 約100 | レンタルはあるのに、**何が借りられて何が足りないか**は書かれていない（例：ひるが海上釣堀は「レンタルタックルが完備」の1文だけ） |
| 持ち物・持参の記載 | 28 | 7割の記事で「自分で用意するもの」が分からない |
| スタッフが教える・手伝う、の記載 | 24 | 「道具の使い方が分からない」への答えがない |
| 魚の締め・捌きサービスの記載 | 26 | 釣った後どうなるかが分からない |
| 釣果保証・お土産・ボウズの記載 | 52 | 「本当に釣れる？」への答えは半分以下 |
| 施設記事から `tactics/beginner/` へのリンク | **0** | 初心者ガイド10本（44〜67行と薄い）は施設記事から孤立している |

一方、アクセスの58%は施設記事、7%はランキング（w42）。**最も読まれている記事が、はじめての人の質問に答えていない**状態。

### はじめての人が持っている不安（答えるべき5つの質問）

| # | 質問 | 記事で答えること | 根拠にするもの |
|---|---|---|---|
| Q1 | 道具がなくても釣りできる？ | レンタルの有無・中身（竿・リール・仕掛け・エサのどこまで含むか）・料金 | 公式サイト・frontmatter（`rental_tackle`・`includes_gear`・`hands_free`） |
| Q2 | 自分で何を用意すればいい？ | 借りられないもの（クーラー・手袋・タオル・飲み物・防寒・酔い止め等）。施設の貸出品（ライフジャケット・クーラー）を除いた差分 | 公式サイト＋共通チェックリスト |
| Q3 | 本当に釣れる？ | 放流の有無、釣果保証・お土産制度の有無、釣れやすい時期 | 公式サイト・`stocked_fish`・`.data-set/fish-knowledge` |
| Q4 | 道具の使い方が分からない | スタッフのサポート有無（エサ付け・取り込み・針外し）。使い方そのものは共通ガイドへ | 公式サイト＋共通ガイド |
| Q5 | 釣れた魚はどうする？ | 締め・捌きサービス、持ち帰り方 | 公式サイト |

- 公式で確認できない項目は推測で埋めず、「**予約の電話で聞くこと**」として書く（はじめての人にはそれ自体が役に立つ）
- 魚種・釣れやすさに触れる部分は `kaijo-fish-knowledge` を通す

## 2. 設計

### 2.1 記事の置き方（経験者の邪魔をしない）

| 位置 | 中身 | 経験者への影響 |
|---|---|---|
| 冒頭（リード直後） | 1〜2行の案内ボックス：「はじめて・道具なしの方へ：レンタル○／持ち物△点 → 詳しく」（節へのアンカー） | 2行だけ。読み飛ばせる |
| 料金の節の直後 | **「はじめての方へ」節**：Q1〜Q5 を表＋短い文で。最後に共通ガイドへのリンク | 独立した節なので目次から飛ばせる |
| FAQ | Q1・Q3 を1問ずつ（検索の「道具なし」「初心者」系クエリの受け皿） | 既存のFAQに追加するだけ |

「メイン魚種の攻略」など経験者向けの節は**そのまま残す**（削らない）。

### 2.2 部品

- **共通ガイド（柱記事）**: `tactics/beginner/first-fishing-pond`（67行）を「海上釣り堀はじめてガイド」として書き直す。道具なしで行ける理由／持ち物チェックリスト／1日の流れ／竿の持ち方・仕掛けの入れ方・タナ・アタリ・取り込み（スタッフがタモ）／本当に釣れるか／釣れた魚の扱い。施設記事の「はじめての方へ」節から必ずここへリンクする
- **「はじめての方へ」節のテンプレート**: Q1〜Q5 の表の型を決め、全施設で同じ並びにする。部品化（`.astro` コンポーネント）するか本文に直接書くかは試作2本で決める。**`src/content/config.ts` は変更しない**（足りない値はコンポーネントの props か本文で渡す）
- **データ収集**: `facility-data-update` の確認項目に「はじめて項目」（レンタルの中身・料金／貸出品／スタッフのサポート／釣果保証・お土産／捌きサービス）を追加。運営者が確認して `> [!forAI]` に書く既存の流れに乗せる

### 2.3 収益とのつながり（11月後半）

- Q2「自分で用意するもの」= レンタルでは借りられない物 = **物販の自然な置き場**（クーラー・手袋・ライフジャケット・冬は防寒）。カードは「借りられない理由」の一文の後に1枚だけ置く
- 遠方の読者には、アクセス節で宿・レンタカー（`kaijo-affiliate-sales` の読者タイプ判定どおり）
- 先に不安を解消してから勧める順番にすることで、売り込み感を出さずにクリック率を上げる
