# はじめてガイド：参考動画の候補

> [!important]
> 「海上釣り堀はじめてガイド」（`src/content/blog/tactics/beginner/first-fishing-pond/`）の Q4「道具の使い方」などに埋め込む YouTube 動画の候補。運営者の方針（`.data-set/first-timer-knowledge.md` §3）は「道具の使い方は参考動画を引用するのがベスト。SEO 上位は狙わず、はじめての人を内部リンクと動画で解決に導く」。
> **運営者が視聴して「採用」と所感を書いたものだけ埋め込む。**

## 調べ方と注意

- 2026-10-27 に YouTube 検索（日本語）の上位から選んだ。視聴回数・公開時期はその時点の値
- 全21本、埋め込み許可（oEmbed で取得可）を確認済み
- 「Claude のメモ」は**タイトル・チャンネル・長さから書いたもので、内容は視聴していない**。釣り方が当サイトの説明（タナはスタッフに聞く、ウキが沈むまで待つ等）と食い違っていないかは、運営者の視聴で確認する
- 埋め込みは `astro-embed` の `YouTube` コンポーネントを使う（`import { YouTube } from 'astro-embed';` → `<YouTube id="動画ID" />`。サイトで導入済み）。1つの節に1〜2本まで
