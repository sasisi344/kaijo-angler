# 旅行アフィリエイト再構築 作業タスク

作成: 2026-09-02 ／ 親タスク: [[next-task]]「アフィリエイト構造の再構築」

## このタスクのゴール

施設記事・アクセスガイドの旅行リンクを「ASPのTOPページ着地」から「エリア・拠点への直接着地」へ切り替え、クリックが成約に繋がる状態にする。

## 前提（確定済み・再調査不要）

- ValueCommerce の **MyLink** なら じゃらんnet・じゃらんレンタカー・楽天トラベルの3つとも `vc_url` でリンク先を指定できる
  - 標準タグ・自由テキストでは不可。この違いを踏まないこと
- `pid` を固定したまま `vc_url` を差し替えて量産できる（`AffiliateCard.astro` の楽天市場検索と同じ方式）
- **sid が商材で異なる**: 楽天トラベル=`3758616` ／ じゃらん系=`3748070`
- じゃらんレンタカーの拠点は都道府県ではなく**主要空港・主要駅（主に新幹線停車駅）**単位
- じゃらんの都道府県スラッグは大阪=`oosaka`・大分=`ooita` のみ長音表記

| 商材 | sid / pid | 遷移先パターン |
|---|---|---|
| 楽天トラベル | 3758616 / 892690738 | `travel.rakuten.co.jp/<都道府県>/` |
| じゃらんnet | 3748070 / 892690810 | `www.jalan.net/ikisaki/map/<都道府県>/` |
| じゃらんレンタカー | 3748070 / 892690812 | `www.jalan.net/rentacar/search/<拠点コード>/plan/?vos=afjlrpvczzzzx00000001` |
