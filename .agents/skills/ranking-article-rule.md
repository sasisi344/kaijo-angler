# ランキング記事ライティングルール

`column/ranking/` 配下の地域別海上釣り堀ランキング記事の作成規則。
確定テンプレートは `src/content/blog/column/ranking/kansai/index.mdx` を参照。

---

## 1. ファイル配置

```
src/content/blog/column/ranking/{region-slug}/index.mdx
```

`{region-slug}` の命名規則：

| 対象エリア | slug |
| :--- | :--- |
| 大阪・兵庫 | `kansai` |
| 三重・和歌山 | `mie-wakayama` |
| 中国・四国 | `chugoku-shikoku` |
| 九州・沖縄 | `kyushu-okinawa` |
| 日本海側・北陸 | `nihonkai-hokuriku` |
| 関東・静岡・愛知 | `kanto-tokai` |
| 北日本・東北 | `tohoku-hokkaido` |

## 2. フロントマター

```yaml
---
title: "【2026年最新】{エリア名}の海上釣り堀おすすめランキング｜{都道府県} 全N施設を比較"
publishDate: YYYY-MM-DD
category: "釣り場ランキング"
draft: false
tags:
  - "ランキング"
  - "{エリア名}"
  - "{都道府県名1}"
  - "{都道府県名2}"
  - "海上釣り堀"
description: "{都道府県}の海上釣り堀N施設を料金・アクセス・魚種で徹底比較。〜目的別おすすめTOP3を解説します。"
---
```

- `image` フィールドは cover.jpg が存在する場合のみ追加する（生成は明示指示があるまで行わない）
- `category: "釣り場ランキング"` に固定（`travel`・`trivia` と区別するため）
- タイトルの施設数 N は<strong>稼働中の海上釣り堀のみ</strong>をカウントする（休止中・閉園は含まない）

---

## 3. 対象施設の選定ルール

**海上釣り堀のみをランキング対象とする。**

施設の frontmatter `tags` に `海上釣り堀` が含まれているものを対象とする。以下は除外する：

| タグ | 除外理由 |
| :--- | :--- |
| `海釣り施設` | 護岸・公営桟橋型（放流管理なし） |
| `海釣り公園` | 護岸・桟橋型の海釣り公園 |
| `status: closed` または `status: suspended` | 閉園・休止中 |

- 休止中・閉園施設は一覧テーブルに残すが、施設名の後に `※2026年〇月より無期限休止中` と明記し、アクセス欄は `—` にする
- タイトルの施設数・TOP3・目的別まとめには含めない

## 4. H2 セクション構成（固定）

以下の順序を守る。

```
## おすすめTOP3
## {都道府県A}の海上釣り堀（N施設）    ← 府県ごとに繰り返す
## {都道府県B}の海上釣り堀（N施設）
## {エリア名}の海上釣り堀を分析する
## 目的別おすすめまとめ
## これだけは持っていきたい！おすすめアイテム
```

---

## 5. 各セクションの書き方

### おすすめTOP3

- 1〜3位それぞれに H3 見出し（`### 1位　[施設名](パス)（都道府県・地区名）`）
- 各位に2〜3文の説明 ＋ `- <strong>料金</strong>：` `- <strong>アクセス</strong>：` の箇条書き
- 選定軸：本格度・旅行適性・初心者向けの3軸で異なるタイプの施設を選ぶ
- 休止中・閉園施設はTOP3に含めない

### {都道府県}の海上釣り堀

- エリアの地理的特徴を1〜2文で書いてからテーブルへ
- テーブルの列：`施設名（内部リンク）` | `特徴` | `アクセス`
- テーブルの後に「エリアの選び方」を箇条書き（目的 → 施設名の形式）

```markdown
| 施設名 | 特徴 | アクセス |
| :--- | :--- | :--- |
| [施設名](/fishing-facility/...) | 特徴を端的に | 最寄り駅・港 |
```

### {エリア名}の海上釣り堀を分析する

プレゼン資料的な俯瞰コンテンツ。以下の4ブロックで構成する：

1. **施設数と分布：{比較対象エリア}との比較**
   - 施設数・国際空港アクセス・放流魚の最高クラス・施設タイプの多様性・旅行適性を5行の比較表にまとめる

2. **地理的優位性：{海域名}が生む「釣り堀の適地」**
   - 海域の地形的特性（内湾・波・潮流）が施設集積を生む理由を2〜3段落で説明

3. **アクセス構造：{主要起点}を起点にした旅行動線**
   - 出発地・手段・所要時間の3列テーブルで主要ルートを示す

4. **施設タイプ別の特性まとめ**
   - タイプ名・該当施設・向いている人の3列テーブルで3〜4タイプに分類する

### 目的別おすすめまとめ

2列テーブル（目的 | おすすめ施設）。6〜8行を目安に、初心者・家族・ガチ勢・電車族・天候別など多様なニーズをカバーする。

### これだけは持っていきたい！おすすめアイテム

```mdx
<TackleCard id="tackle/gamakatsu-cut-madai" />
<TackleCard id="tackle/daiwa-kaijo-uki" />
```

## 6. 全体の記述ルール

- 強調は `<strong>テキスト</strong>` を使用（`**bold**` は使わない）
- 施設への内部リンクは `/fishing-facility/{region}/{prefecture}/{slug}` の絶対パスで書く
- 「あわせて読みたい」セクションはリンク先の記事が存在する場合のみ追加する
- `import TackleCard from "~/components/common/TackleCard.astro";` を frontmatter 直後に記述する
