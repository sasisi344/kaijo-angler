# カード規約（物販カードの書き方の型）

`<TackleCard />`・物販の `<AffiliateCard />` を記事に置くときの**書き方の正本**。挿し方（import・props）は `.claude/skills/kaijo-ui-components/SKILL.md`、旅行（宿泊・レンタカー・GoThere）の売り方は `.claude/skills/kaijo-affiliate-sales/SKILL.md` を見る。

- 制定: 2026-11-09（hq:H-39 AF-1。元は `344blog/hq/affiliate-copy-rewrite.md` §2、2026-11-08 ユーザー指示）
- 実例: KA-2 の4本（2026-11-09 検収済み。`.workspace/admin-review/2026-11-09-KA-2.md`）

## 1. 目的

「記事を読んだうえで道具が欲しくなり、そこにたまたま商品リンクがあるから買う」流れを作る。カードを並べるだけの書き方はしない。

## 2. 型（カード1枚ごとに5段）

| 段 | 書くこと | 注意 |
|---|---|---|
| 1. 場面 | 読者がその釣り場・その旅で出会う具体的な場面（いつ・どこで・何が起きるか）。読者を主語に、現在形で書く | 一般論から入らない。「〜する場面を考えてください」のような仮定の指示で始めない（§3-2） |
| 2. 原因 | なぜそれが起きるかを、魚の習性・潮・道具の仕組み・輸送の規定で説明する | 数値はナレッジ（`.data-set/fish-knowledge/`）か公式に出所のあるものだけ。公式は確認日を書く |
| 3. 選ぶ基準 | 解決に必要な条件を、数字や仕組みで示す（号数・長さ・素材・容量・保冷時間・3辺合計など） | 読者が自分で判断できる基準にする。基準は `<strong>` で1か所だけ強調してよい |
| 4. 差し出す | 「その条件を満たすものの一つ」としてカードを置く | カードの直前の文は、基準とつながる一文にする。`reason` も同じ場面と基準で書く |
| 5. 正直さ | カードのあとに、合わない人・代わりの選び方を一文 | レンタル・現地で買う・施設のセットを使う など |

## 3. 実例（`tactics/gear/harris-importance`）

```mdx
朝いちばんのマダイをタモに入れたあと、ハリスを指でなぞると、ざらっとした傷がある。
次の一投の前に結び直すかどうかで、2匹目が変わります。                      ← 1. 場面（読者が主語・現在形）

狙う魚に合う号数でも、結び目が締まりきらず糸が傷んでいれば、
そのまま使い続けられません。                                              ← 2. 原因

選ぶ条件は、<strong>必要な号数があり、自分で結びを整えやすい糸質であること</strong>です。 ← 3. 基準

[シーガー公式](https://www.seaguar.ne.jp/lineup/fcharisu/fc_5.html)では、グランドマックスFXを
しなやかさを加えたフロロカーボンハリスと案内しています（2026年11月9日確認）。
その条件で選ぶ製品の一つです。                                            ← 4. 差し出す

<TackleCard id="tackle/seaguar-grandmax-fx" placement="gear-harris"
  reason="マダイ用とブリ用を自分で結び分ける人へ。傷を見つけたその場で結び直しても、結び目が締まりやすいしなやかなフロロハリスです。" />

自分でハリを結ぶ準備がない人は、現地の完成仕掛けやレンタルを選ぶと、
太さとハリの組み合わせを相談できます。                                    ← 5. 正直さ
```

（実際の記事では1〜2文ごとに空行で段落を分ける）

## 3-1. 運用の決定（2026-11-15 ユーザー、hq:H-39 AF-2 の6本を読んで）

正本は `344blog/hq/affiliate-copy-rewrite-af2-review.md` §4-2。

1. **5段は全カード必須**。ただし「選ぶ条件は、<strong>〜</strong>です」「〜が候補になります」などの定型句は**1記事2回まで**。残りは言い回しを変える。基準の `<strong>` 強調も毎回は付けない
2. **枚数は「欲しくなる場面の数」だけ**。本文にすでに場面がある商品は外さず5段で書く。場面を新しく作って枚数を増やすことはしない
3. **正直さの一文は全カードに入れる**。「買い足す必要はない」「レンタルで十分」の言い方は**1記事2回まで**。代わりの選び方（現地で借りる・施設に相談する・号数を選び直す）を書く形を優先する
4. **事実の扱い**: Codex が扱う事実は、元の記事の記述と、指示書の材料に載せた CC のリサーチ（出典・確認日つき）だけ。疑わしい事実は消さずに報告する（`344blog/hq/org/codex-worker.md` §2）。公式が開けないことを理由に、料金・営業時間・タックル例を消さない
5. **1カードの文章量**: 1枚につき4〜6段落・250〜350字を目安にする。仕様の数値は基準に使うものだけ書き、並べない（志布志の内寸・外寸・自重のように詰め込まない）

**記事の種類ごとの見本**

| 種類 | 見本 | 見るところ |
|---|---|---|
| ランキング | `column/ranking/kansai` | 1枚目は**TOP3 の直後**（行き先を決めた直後）。2枚目は場面がある記事だけ、結びの前に置く（2026-11-19 確定。[ranking-article-rule.md](./ranking-article-rule.md) §5） |
| 遠征先の施設 | `fishing-facility/west-japan/okinawa/itoman-ikada-tsurigu-no-zousan` | 現地で補助を頼めるか相談する、を正直さに置く |
| 家族向けの施設 | `fishing-facility/west-japan/miyazaki/shibushi-bay-daikoku-dolphin-land` | 施設の規則（全買取制）を原因にする |

## 3-2. 欲しくなる書き方（2026-11-15 追加。2026-11-19 確定）

正本は `kaijo-writing-rule.md` §4。AF-2・AF-3 の14本は5段がそろっているのに、11/06〜14 の9日間はカードのクリックが0件だった（公開は 11/08〜15 で、判定にはまだ早い。早めの警告として扱う）。5段の「場面」が仮定の手順になり、`reason` が仕様の照合になっていた。5段の枠は変えず、中身の書き方を次のように決める。

1. **場面は情景で書く**: 読者が主語、現在形、その釣り場で実際に起きる順。場面の1〜2文で、魚の重さや冷たさが浮かぶところまで書く。体験談（「私は〜した」）にはしない
2. **原因の前に、困ることを書く**: 「払った料金」「釣った魚」「その日の残り時間」のどれが無駄になるかを1文で。料金は施設記事の数値を使う
3. **`reason` は「誰が・どの場面で・どう助かるか」**: 仕様の語（耐荷重・開口幅・錘負荷・照合・確認）で終えない。仕様は本文の「基準」に1回書けば足りる。`reason` の末尾を「〜を確認してください」にしない。「〜の候補です」は §3-1 の定型句（1記事2回まで）に含む
4. **正直さは肯定の文で**: 「買い足す必要はありません」ではなく「貸し竿のセットで始めれば、道具は現地でそろいます」。合わない人を追い返す文にせず、その人の次の一手を書く
5. **確認の語をカードの周りに集めない**: カード1枚（5段）の中で「確認・確かめ・相談・照合」は合わせて2回まで。出典と確認日は基準の文に1回

| | 今の書き方 | 直した書き方 |
|---|---|---|
| 場面 | 「貸し竿で青物を釣った後、針外しをスタッフへ頼むか、自分で魚を保持するかで持ち物が変わります」 | 「タモの中でブリが首を振るたび、口元の針が光ります。ここで素手を出すかどうかです」 |
| reason | 「魚に見合う耐荷重と開口幅を照合し、口を保持するために選ぶグリップです」 | 「釣れた青物の針を自分で外したい人へ。暴れる魚の口をつかんで、手を針から離したまま持てます」 |
| 正直さ | 「貸し竿を選んだ人が全員、自分で保持する道具までそろえる必要はありません」 | 「はじめての日は、巡回のスタッフに針外しを頼めば手ぶらで足ります」 |

## 4. 枚数・置き場所

- カードの枚数は「欲しくなる場面」の数だけ。場面のないカードは外してよい
- 記事の終わりに「おすすめタックル」の節を作ってまとめて置かない。場面の節の中に置く
- ランキング記事は、ランキングと比較を読み終えた後の節に置く
- 同じ記事・同じ商品のカードは1枚まで

## 5. reason・誘導文

- `reason` と誘導文は、その記事のその場面のことだけを書く。ほかの記事と同じ文を使わない
- 書き出しは「◯◯する人へ」「◯◯のときの」など、場面と読者を名指す形にする

## 6. placement（計測）

- すべてのカードに `placement` を付ける。値は `{記事の種類}-{場面}`（例: `gear-harris`・`travel-cooler`・`winter-buri`・`facility-gear`）
- 付け忘れたカードは、クリック時に直前の H2 見出しから `auto:{見出し}` が自動で入る（2026-11-09 から）。これは取りこぼし対策で、新しく書くカードは必ず明示する
- GA4 では `affiliatecard_click` の `placement`・`affiliate_id`・`shop` で見る

## 7. 書かないこと

- 使用感・「買ってよかった」（筆者の記録がない）。一人称の体験を作らない
- 「最強」「必ず」「最安」と価格
- `src/content/affiliates/` にない ID。新しい ID は CC が作る（Codex は作らない）
- 「PR」の札はカード側で自動で出るので、本文に「PR」「広告」と書き足さない

## 8. 書いたあとのチェック

- [ ] カードごとに、場面→原因→基準→カード→合わない人の一文がそろっている
- [ ] 原因・基準の数値に出所（ナレッジの節か、公式と確認日）がある
- [ ] `reason` が記事固有で、ほかの記事と同じ文ではない
- [ ] すべてのカードに `placement` がある
- [ ] 場面のないカードが残っていない
- [ ] 場面が「〜を考えてください」「〜を想定します」で始まっていない。読者が主語の現在形になっている（§3-2）
- [ ] `reason` が仕様の照合・確認で終わっていない
- [ ] カード1枚の周りの「確認・確かめ・相談・照合」が2回まで
- [ ] 場面が読者の選択を決めつけていない（「〜に決めた人は」の条件で書いている）。困る結果を書いたら、次の文に一手がある（`kaijo-writing-rule.md` §4.1-1・§4.4）
