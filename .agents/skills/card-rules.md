# カード規約（物販カードの書き方の型）

`<TackleCard />`・物販の `<AffiliateCard />` を記事に置くときの**書き方の正本**。挿し方（import・props）は `.claude/skills/kaijo-ui-components/SKILL.md`、旅行（宿泊・レンタカー・GoThere）の売り方は `.claude/skills/kaijo-affiliate-sales/SKILL.md` を見る。

- 制定: 2026-11-09（hq:H-39 AF-1。元は `344blog/hq/affiliate-copy-rewrite.md` §2、2026-11-08 ユーザー指示）
- 実例: KA-2 の4本（2026-11-09 検収済み。`.workspace/admin-review/2026-11-09-KA-2.md`）

## 1. 目的

「記事を読んだうえで道具が欲しくなり、そこにたまたま商品リンクがあるから買う」流れを作る。カードを並べるだけの書き方はしない。

## 2. 型（カード1枚ごとに5段）

| 段 | 書くこと | 注意 |
|---|---|---|
| 1. 場面 | 読者がその釣り場・その旅で出会う具体的な場面（いつ・どこで・何が起きるか） | 一般論から入らない |
| 2. 原因 | なぜそれが起きるかを、魚の習性・潮・道具の仕組み・輸送の規定で説明する | 数値はナレッジ（`.data-set/fish-knowledge/`）か公式に出所のあるものだけ。公式は確認日を書く |
| 3. 選ぶ基準 | 解決に必要な条件を、数字や仕組みで示す（号数・長さ・素材・容量・保冷時間・3辺合計など） | 読者が自分で判断できる基準にする。基準は `<strong>` で1か所だけ強調してよい |
| 4. 差し出す | 「その条件を満たすものの一つ」としてカードを置く | カードの直前の文は、基準とつながる一文にする。`reason` も同じ場面と基準で書く |
| 5. 正直さ | カードのあとに、合わない人・代わりの選び方を一文 | レンタル・現地で買う・施設のセットを使う など |

## 3. 実例（`tactics/gear/harris-importance`）

```mdx
釣り場でハリスに傷を見つけ、ハリを結び直す場面を考えてください。            ← 1. 場面

狙う魚に合う号数でも、結び目が締まりきらず糸が傷んでいれば、
そのまま使い続けられません。                                              ← 2. 原因

選ぶ条件は、<strong>必要な号数があり、自分で結びを整えやすい糸質であること</strong>です。 ← 3. 基準

[シーガー公式](https://www.seaguar.ne.jp/lineup/fcharisu/fc_5.html)では、グランドマックスFXを
しなやかさを加えたフロロカーボンハリスと案内しています（2026年11月9日確認）。
その条件で選ぶ製品の一つです。                                            ← 4. 差し出す

<TackleCard id="tackle/seaguar-grandmax-fx" placement="gear-harris"
  reason="マダイ用とブリ用を自分で結び分ける人へ。必要な号数を選び、しなやかな糸質も比較したいときのフロロハリスの候補です。" />

自分でハリを結ぶ準備がない人は、現地の完成仕掛けやレンタルを選ぶと、
太さとハリの組み合わせを相談できます。                                    ← 5. 正直さ
```

（実際の記事では1〜2文ごとに空行で段落を分ける）

## 4. 枚数・置き場所

- カードの枚数は「欲しくなる場面」の数だけ。場面のないカードは外してよい
- 記事の終わりに「おすすめタックル」の節を作ってまとめて置かない。場面の節の中に置く
- 同じ記事・同じ商品のカードは1枚まで

## 5. reason・誘導文

- `reason` と誘導文は、その記事のその場面のことだけを書く。ほかの記事と同じ文を使わない
- 書き出しは「◯◯する人へ」「◯◯のときの」など、場面と読者を名指す形にする

## 6. placement（計測）

- すべてのカードに `placement` を付ける。値は `{記事の種類}-{場面}`（例: `gear-harris`・`travel-cooler`・`winter-buri`・`facility-gear`）
- 付け忘れたカードは、クリック時に直前の H2 見出しから `auto:{見出し}` が自動で入る（2026-11-09 から）。これは取りこぼし対策で、新しく書くカードは必ず明示する
- GA4 では `affiliatecard_click` の `placement`・`affiliate_id`・`shop` で見る

## 7. 書かないこと

- 使用感・「買ってよかった」（筆者の記録がない）。一人称の体験を作らない
- 「最強」「必ず」「最安」と価格
- `src/content/affiliates/` にない ID。新しい ID は CC が作る（Codex は作らない）
- 「PR」の札はカード側で自動で出るので、本文に「PR」「広告」と書き足さない

## 8. 書いたあとのチェック

- [ ] カードごとに、場面→原因→基準→カード→合わない人の一文がそろっている
- [ ] 原因・基準の数値に出所（ナレッジの節か、公式と確認日）がある
- [ ] `reason` が記事固有で、ほかの記事と同じ文ではない
- [ ] すべてのカードに `placement` がある
- [ ] 場面のないカードが残っていない
